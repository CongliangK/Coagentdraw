# 阶段三｜创意提案

填写目标：围绕同一个角色意图，提出有实质区别的设计解法。

人和 AI 使用同一张表。按「共同问题 → 候选方案 → 比较与选择」填写；先讲清楚想法，再用粗图表达。

## 一、共同问题：这些方案都要解决什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色意图 | 引用[意图卡](01_立项定位.md)，点明本轮最重要的身份、核心幻想与功能，不重新设定另一名角色 | |
| 关键矛盾 | 哪两个要求之间的张力值得转成设计？需要怎样的解法才能同时成立？ | |
| 共同依据与限制 | 从[调研](02_前期调研.md)中选用哪些依据？所有候选必须保留什么、避开什么？ | |

## 二、候选方案：这个想法怎样成立？

为每个方向填写一组。先提出 2—3 个不同解法，区别应落在功能、结构或表达方式，不能只换装饰和颜色。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 方案名称与一句话概念 | 用短句说清这个方向最吸引人的想法 | |
| 关键解法 | 角色怎样行动或使用装备来解决上述矛盾？ | |
| 视觉母题 | 用什么形状、物件或动作承载核心幻想？说明与身份、功能的联系 | |
| 整体想象 | 主要比例、轮廓、服装与道具关系是什么？把抽象表达词落到可画的特征 | |
| 粗略示意 | 用草图、拼贴或生成图表达整体，填写图的位置；未画的写“待画”，不假装已有视觉证据 | |
| 成立理由 | 这一方案如何实现角色意图？说明借用了哪条参考、做了什么转化 | |
| 最值得验证的地方 | 写出一个具体风险，以及下一阶段画什么才能判断它是否成立 | |

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 完成判断 | 候选是否具有不同的解法，并能说明各自的吸引力与待验证问题？若只有换色、换饰品，回第二部分重新发散 | |
| 进入探索的候选 | 选出值得继续的方向，带着具体问题进入[方向探索](04_方向探索.md)；此时保留比较空间，不急于锁定最终稿 | |
