# 参考记录模板

## 先填薄版（三条链可放同页）

| Q / S | 来源与事实位置 | 结构→原创转化 | 权利/未知/反证 | 下一步 |
|---|---|---|---|---|
| | | | | |

补充项目/版本、输入意图版本、执行者/决策者、板路径与证据状态即可开始。复制行形成三条问题链。以下详细条目按需查阅；外部来源/图像必须有出处与使用限制，不能以薄版免除。

## 按需展开来源条目

项目 / 版本 / 日期 / 执行者：
意图卡路径与版本：
Q 问题 / I 约束：
分类（文化与职业、装备功能、服装材料、造型表达、同类对比）：
主参考或补充参考 / 选择理由：

每条来源复制以下段落，至少三条独立链：

## S__ 标题

- 作者/机构、标题、日期（未列则写未列）、原始 URL、访问日期：
- 已查阅正文的位置（节名即可）、可核查事实：
- 看到的结构（分析）：
- 为什么适合（设计推断）：
- 准备怎样原创转化（不能只写换色）：
- 对应板面区域/箭头、提案 ID：
- 风险 / 反证 / 下一步验证：
- 图片作者、授权与限制（未知就写未知；未知不得当已获转载许可）：
- 离线文件路径及实际存在状态（仅链接则说明需联网）：
- 事实核验状态 / 图像使用状态：

## 交接

三条链是否分别支撑不同问题：
尚空类别及原因：
已确认 / 待研究 / 接手者与下一步：
人工验收人、日期、证据（未进行写待验证）：
