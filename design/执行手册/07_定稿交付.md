# 阶段七｜定稿交付

填写目标：整理一份能让自己或接手者 **看懂角色、找到文件、继续制作** 的设计资料。

人和 AI 使用同一张表。按「确认用途 → 准备必要图与说明 → 检查交接」填写；图件按实际需要选择，不需要的写明原因，不默认制作完整三视图或 3D 资料包。

## 一、这些资料接下来用来做什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 后续用途 | 谁接着做什么？是继续画插画、绘制其他姿态，还是制作模型等？接手时必须能回答哪些问题？ | |
| 已定稿件 | 引用[阶段六](06_评审收敛.md)确认的角色稿与关键说明；还有哪些未解决之处会妨碍后续使用？ | |
| 必须保留 | 哪些比例、剪裁、配色、道具或不对称特征决定角色身份？哪些允许随姿态与表现方式变化？ | |
| 文件要求 | 根据用途约定画幅、分辨率、格式、透明背景等；交付位置在哪里，需要哪些可编辑文件？ | |

## 二、哪些图与说明能把设计讲清楚？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色主图 | 展示整体比例、主配色、关键剪裁与身份特征；填写采用的图件，以及尚需整理的地方 | |
| 必要辅助视图 | 主图看不清什么，下一步又必须知道什么？据此选正、侧、背或局部视图，写清每张要解决的问题与图件 | |
| 细节拆解 | 只放大需要解释的部件，用箭头和短注说明固定、穿脱、持握、活动与材料关系；记录对应图件 | |
| 表情与姿态 | 后续制作是否需要知道性格、动作幅度或衣物装备如何随动作变化？需要才补图，并写其用途 | |
| 设计说明 | 图上难以直接表达的功能、材质、保持要点或允许变化是什么？把说明放到对应部位，避免只写抽象气质词 | |

## 三、交出去以后能否继续制作？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 跨视图核对 | 有多视图时，在 Krita 用头顶、肩、腰、膝等水平参考线核对比例与构件位置；区分透视变化与真正画错，检查左右与不对称关系 | |
| 图文一致 | 对照主图检查辅助图、拆解与说明的形状、连接、配色和材料；矛盾要先修，不能靠排版掩盖 | |
| 可编辑源文件 | 另存并重新打开实际 `.kra` 文件，检查角色、道具、说明等图层能继续编辑；保留原稿，不为整理而擅自合并或删除图层 | |
| 导出与查找 | 导出所需预览，核对尺寸、裁切、透明背景和文字可读性；写出主图、辅助图、说明与源文件的实际位置 | |
| 接手检查 | 实际打开资料后，能否找到已定稿、看懂关键结构、知道哪些特征要保持？请实际接手者确认；自用则自行检查，未检查写待确认 | |
| 完成或补回 | 所需图件一致、源文件可编辑且交接清楚才完成；缺图留本阶段补，设计本身仍有矛盾回[阶段六](06_评审收敛.md)。继续画插画时交[阶段八](08_最终插画.md) | |
