# 阶段四｜方向探索表

填写目标：把概念变成可比较的小稿，找出 **哪些形状、结构与色彩关系最能表达角色**。

人和 AI 使用同一张表。按「探索问题 → 画出变体 → 比较候选」填写；新稿另存或放在新图层，保留原稿。填写内容可附图或写图稿位置。

## 一、探索问题：这轮要看清什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 承接提案 | 从[创意提案](03_创意提案.md)选出要画的方向，注明最值得验证的想法 | |
| 本轮问题 | 对照[角色意图](../阶段一_角色意图卡_模板.md)，希望哪种感受更清楚？准备改变什么来检验？ | |
| 比较条件 | 统一展示高度、背景、视角和相近姿态；保留各案自身比例。案内比较尽量一次只改一组变量，另做姿态探索 | |

## 二、视觉实验：怎样把差异画出来？

先用低成本小稿比较至少两个明显不同的方向，再展开有潜力的候选。每项记录「改了什么、看到了什么」，附对应图稿；只把已有图填黑还不算新的造型探索。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 剪影：比例与重心 | 用纯黑画身体、服装、道具三个大块；拉开头身比、肩胯宽、四肢长度、重心与道具体量，比较角色气质 | |
| 剪影：形状与负形 | 改圆、方、尖等主导形状及道具位置；检查手臂与躯干、双腿、道具与身体之间的空隙，缩小看轮廓是否分开 | |
| 结构：剪裁与层叠 | 在候选剪影上画领口、肩线、腰线、开衩和层叠关系；比较长短、宽窄、对称变化怎样强化身份与大形 | |
| 结构：材料与连接 | 标出软布垂落、硬件支撑、穿脱开口和固定位置；画不清的连接补局部，不用装饰遮住结构问题 | |
| 结构：动作功能 | 画一个代表性动作，检查持握、取放、关节和衣物活动空间；圈出冲突，改后用同一动作复查 | |
| 明暗：读取顺序 | 固定结构，先用黑、灰、白分大块，比较焦点位置与面积；缩小看，是否先注意到最重要的部位？ | |
| 配色：身份与情绪 | 在灰阶关系上试少量主色、辅助色和强调色；放到预期背景中比较，再去色看主次是否仍清楚 | |

## 三、候选比较：哪些值得继续？

把候选以相近完成度并排。远看整体识别，近看结构与材料；依据意图说明优势与代价，不用细节多少或总分代替判断。
