# 阶段3｜创意汇总与选择

> 现行手册；稳定 ID：`concept_selection`。工具能力见[能力说明](<../工具能力与验证.md>)；共用规则见[手册导航](<README.md>)。

把多个文本起点和不同素材簇唤起的创意先在 Web 图库分组、标注并比较；需要自由并置、粗图或拼贴时，再把选中素材带入 Krita 提案比较板，短摘要、参考簇、初步意象、可选粗图各自可看可移。可以跨人物、幻想和立项选择，也可拆分、合并；选择范围由本轮任务决定。作者看图文组合选本轮主线，AI 解释差异而不代投票。

已有角色与主线明确时，沿用当前决定和设计锚点，直接到 [04](<04_角色视觉探索.md>)设计服装／核心物件草案并与整身试装往返；已有可用部件或原型则继续当前问题，不要求全部部件先定稿。不为填写“跨创意”而另造人物。02 的角色候选是参考来源候选，不自动成为本项目的人物候选。试拼反馈可以帮助调整主线；只有确实需要重新取舍时才回本阶段。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 候选创意 | 给创意短名，关联起点和素材簇，不只放单张参考图 | |
| 最值得做的部分 | 这个创意的核心幻想是什么，要为观众、玩家或读者提供怎样的想象？具体最值得发展的部分是什么？ | |
| 相对区别 | 与其他候选真正不同在哪里？ | |
| 代价与未知 | 有哪些值得后续画图验证的问题？不必现在全解答 | |
| 决定 | 选中、继续观察、暂存、不做本轮或拆分合并 | |
| 理由与适用范围 | 是本轮偏好、资源取舍，还是确实违反已确认约束？ | |
| 交给视觉探索 | 用简短创意说明、当前锚点和对应画布，交代要保留的体验；引用02尝试记录 | |

**完成与交接：** 作者明确本轮主线，未选创意保留去向；全无吸引力就回一、二阶段。粗糙但有潜力的起点不应输给纯完成度。“这次不选”不是全局永久禁令，也不自动写 negative prompt。
