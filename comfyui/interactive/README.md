# Qwen 2.1 局部编辑：画质优先基线

将 [qwen21_localedit_hq.json](qwen21_localedit_hq.json) 拖入 ComfyUI。它是交互格式，不通过 `cwb --wf` 使用；根目录仍只维护两条 CLI API 模板。

当前图包含原图、蒙版、裁切、模型采样与拼回分支。HQ 表示画质优先的配置目标，不表示已经证明是最高质量。

## 使用

1. 在原图节点选择图片，右键打开遮罩编辑器，涂抹要修改的区域并保存到节点。遮罩白为重绘、黑为保留；普通不透明图片默认没有有效编辑遮罩，必须先画遮罩。不要直接运行空遮罩：该第三方节点会退回整图裁切范围。
2. 修改提示词，描述目标部件的形状、材质、颜色及与周围的关系。遮罩覆盖整个需要改变的部件，边缘尽量落在自然分界处。
3. 先检查遮罩，再运行。裁切预览用于核对送入模型的视野，保存节点输出拼回原图后的完整图片，另有原图预览便于并排查看。
4. 首轮固定种子 42 做参数比较；结果符合方向后，再换种子挑选候选。保存文件前缀为 `qwen21_localedit_hq`，不覆盖输入源图。

## 配置与取舍

- 完整基础模型采样：Euler / simple、30 步、CFG 1、降噪 1。未加载六步/八步加速、换头/换身或一致性 LoRA，避免默认叠加未经对照的影响。30 步是基线，不是经实测确定的质量最优点。
- 裁切目标 1024×1024，上下文系数 1.5；不预缩放整张原图。裁切节点通过扩展上下文匹配目标比例，再缩放处理。实际细节仍受原图、裁切范围与模型能力限制。
- 文本条件的 image_1 与 VAE 编码都使用同一裁切输出，避免用整图条件指导一个局部窗口。第二参考图未接入；遮罩通过噪声约束提供空间限制，不作为模型图像参考。
- 遮罩外扩 16 像素、融合 32 像素，关闭自动填洞，保留手绘保护孔。最终变动范围包含外扩与融合带，不能声称原始遮罩外全部不变。严格边界任务可将外扩设为 0 并降低融合宽度，但更容易出现接缝。
- 大改造保留降噪 1；只修纹理可尝试降低至 0.6–0.85，再检查原瑕疵是否残留。不要一次修改多个相距很远的小区域，否则上下文窗口会变大、每个部件的有效分辨率降低。
- 显存不足先将裁切目标降到 768；细节较大且显存允许时再比较 1280/1536。更大尺寸、更高步数不保证更好。

## 依赖与验证边界

基础模型：`qwen_image_2.1_int8_convrot.safetensors`；编码器：`qwen3vl_8b_int8_convrot.safetensors`；VAE：`qwen_image_2.1_vae_bf16.safetensors`。这里沿用本机已有模型，并非全精度模型的质量上限。

需支持 `TextEncodeQwenImage21`、`QwenImage21Cache` 的 ComfyUI，以及 `ComfyUI-Inpaint-CropAndStitch` 的 `InpaintCropImproved` / `InpaintStitchImproved`。无 rgthree、Easy Use、KJNodes 依赖。

已核对参考 JSON、安装节点的输入与裁切实现，以及生成工作流的双向连线、必需采样输入、模型路径命名。尚无该模板的真实生成、显存峰值与艺术验收证据。后续应以同图、同遮罩、同种子比较 768/1024 与 25/30 步，检查意图、接缝和最终有效编辑范围外的像素差。
