## 共用视觉与安全规则

- 图像判断回到 Krita；引用记录文档、本地 KRA、组/层或画布区域及预览版本，不能只写“图3”。参考、候选、主稿与诊断分身份，原图保留。
- 线稿和基础色需真实可分别处理；AI 位图不冒称语义分层。新结果先作候选，接受/拒绝由作者决定。叠加不能冒充擦除旧线的替换。
- 对比提供同尺度全图和局部。拒绝保留原稿与候选；可见性恢复遇人工变动先查冲突。
- 目标不清、源改变、无有效选区/映射不回填；无选区不默认为整图，超时未知先查结果不盲重试。保存/覆盖须在授权内。
- 本地 KRA 是可编辑源，PNG 是预览/交换；保存重开与最终导出都需实际检查。工作文件与不变批准快照分开；批准绑定版本、范围与真实人类来源。
- 项目关注阶段、模型执行、人类艺术验收分别记录。A 离线、B 实机、C 真实创作分别给证据，空表与测试成功不等于作品通过。
- 原生参考图可人工辅助，但画布投影不一定含画布外参考，不能冒称 AI 已看见。默认共享板用普通层/组，素材分批分页，不取消资源保护。
