# 子代理调研素材：中日厂商 + 通用方法论（子代理 09996730 返回，来源已核验）

## A. 公司实战流程

### A1. 米哈游 miHoYo / HoYoverse
**核心发现：刻意不固化流程。** 绝区零制作人李振宇（Denfaminicogamer 采访，Automaton 编译）："我们没有单一固定的角色创作流程……如果固定一种工作流，只会限制我们做出有趣设计的能力。"甚至让动画团队先提出"有趣的动作"再反过来构建角色；文案、美术之外各部门都被鼓励参与角色设计。名言："**角色设计的过程就是沟通的过程**"。来源：https://automaton-media.com/en/news/zenless-zone-zeros-flashy-character-designs-are-a-result-of-the-dev-team-not-wanting-to-settle-on-just-one-character-creation-method-it-would-only-limit-our-ability-to-create-intere/

**星穹铁道：角色先于战斗、多轮迭代变美。** 主设计师安成南（GDC 2025，Polygon 专访）："如果只从战斗系统出发，灵感很快就枯竭"——武器可从人设倒推（真理博士用厚书砸人、姬子大招端茶杯）。每个角色立项时大量采访团队成员收集反馈，多轮迭代"每次迭代都会变得更漂亮、更帅、更酷"。来源：https://www.polygon.com/features/549920/honkai-star-rail-lead-designer-interview/

**原神：官方幕后披露设计迭代链路。** HoYoLAB 官方专栏《原神幕后》角色篇（第4部分讲魈）：第一次企划会议后基于"少年战士"概念做出初稿，再经多轮评审迭代成最终版。来源：https://www.hoyolab.com/article/182444 ；社区整理各角色官方设计笔记：https://genshin-impact-fandom.com/wiki/Xiao/Design 。云堇：官方纪录片《云堇创作的幕后——戏中人间》显示上线前 4 年即完成设计，京剧元素请专业演员动作捕捉与文化考证。来源：http://news.yxrb.net/202201/14228309.html

### A2. 库洛 / 鹰角 / 腾讯 / 网易
**库洛《鸣潮》官方 2.X 开发组对谈**：角色管线 = "文案+战斗策划出概念 → 原画创作 → 动作/特效共创"。以仇远为例：先定"国风盲人剑客"（"这些做出来他只是一个及格的角色"）；针对"盲人"做发散（超感知/心眼），选定"竹"作为新感官概念载体，"概念一抛出全团队都有创作欲"，才有水墨氛围与墨竹轻功。→"基础标签→找差异化痛点→意象载体→全员脑暴"的发散方法。来源：https://m.163.com/dy/article/KCHNR5U505268BP2.html

**腾讯天美 TGDC《王者荣耀》角色设计及世界观包装（美术副总监战涛）**：
- 中国古代人物元素 + 现代流行服饰剪裁；避免复杂花纹，"更多在大剪影造型上下功夫"（MOBA 快速识别取决于剪影轮廓）。
- 东西方审美差异：西方需契合故事与世界观的合理性（战神变老、劳拉去性感化）；东方用户偏好美型精致，关键词"权力、智慧、金钱、美貌"，喜欢"强大到弹个手指敌人就死"。
- 用户认同三层次："我能像他一样战斗 / 他和我有很多相似点 / 他是我想成为的样子"。
- 用研观："不是用户喜欢什么就做什么，而是通过了解用户，把希望传达的内容设计出来让用户认可。"
- "故事背景至关重要，不然它只是一张皮、一个花瓶。"
来源：https://gameinstitute.qq.com/course/detail/10139

**网易**：校招 JD 明确要求"角色原画设计、三视图/拆解图（callout）产出、与3D对接"。https://hr.game.163.com/position/introduction.html?code=70590

### A3. 日本：任天堂 / 万代 / 职位体系
- **任天堂 BotW**：林克近 100 版重设计才定蓝色 tunica（绿帽装在新美术里与草地环境冲突、辨识度差）。塞尔达公主被称为最难设计（气质需同时传达学者与统治者）。来源：https://www.nintendolife.com/news/2018/12/close_to_100_link_designs_were_considered_for_zelda_breath_of_the-wild_devs-explain-blue-tunic ；Iwata Asks 记录跨部门协作：https://www.nintendo.com/en-za/Iwata-Asks/...
- **万代南梦宫（藤岛康介，传说系列30周年访谈）**：甲方给 direction，插画师在遵循与自我间平衡；自设约束——"想象比现代早得多的时代，避免拉链等不存在的技术""设计要保证角色旅行时不便"；"太遵循统一美学会失去角色独特性"。来源：https://www.bandainamcoent.com/news/tales-of-30th-anniversary-interview-with-kosuke-fujishima
- **日 vs 西体系差异**：日本"一名角色设计师（常为知名插画家）统包设定画+立绘+表情差分"的作者制；欧美 concept artist 团队流水线。日本将角色作为品牌资产放 UI 中心、角色衍生商品化；西方以世界观合理性优先。来源：https://business.4gamer.net/article/2505/25051201/ ；职种说明：https://creator.levtech.jp/jobguide/detail/15/

### A4. 外包协作（核实：原画人是教学平台；维塔士主业 3D）
四阶段模型（Saigon Dragon Studios，业内通用）：
1. **Brief intake**：甲方交付 brief（性格/定位/世界观约束 + 2-3 张风格参考"而非30张互相矛盾的moodboard" + 技术规格 + 唯一反馈接口人 + 里程碑日历），外包方回传"复核后的 brief+参考板"——此阶段改方向成本最低。
2. **Concept sketches**：多方向黑白/限色草稿，只评剪影/比例/姿态，"反馈聚焦结构而非表面细节"。
3. **Refinement**：全彩 turnaround + 材质细化，此处改设计代价中等。
4. **Final**：验收与规格校验，之后改动=返工。
纪律：**单一反馈出口**；每阶段明确"此刻批准的是什么"。来源：https://saigondragonstudios.com/2026/08/11/character-art-outsourcing-brief-to-approved-four-stages/

## B. 通用方法论

### B1. 标准流程模型
调研（参考板/情绪板）→ thumbnails（8-20个，只求量与差异）→ silhouette（纯黑形块验证远距可读）→ 线稿 → color study（小尺寸快速配色）→ 细化 → 立绘。来源：https://www.proko.com/course/the-character-concept-art-course 、https://80.lv/articles/character-design-development-from-concept-to-final-illustration
- **iterative design loop**：宽（发散）→窄（评审淘汰）→宽（选定方向再发散）的漏斗。
- 两派价值取向：**form follows function**（欧美主流）vs **aesthetic-first**（二次元/东方主流，星铁"每轮迭代都变好看"）——王者演讲给出文化成因分析。

### B2. 头脑风暴
- **Crazy 8s**：纸对折三次8格，8分钟画8个变体；变体 Evil 8s 反向专画坏点子。
- **Bad ideas first**：先列最烂方案解除心理门槛。
- **约束激发创意**：藤岛"不用拉链、必须能旅行"；鸣潮"盲人如何战斗？"。
- **Theme / Fantasy / Function 三层论**：主题定位→玩家自我投射→功能需求；与 TGDC 用户认同三层次直接映射。
- **形状语言**：圆=友善、方=稳定、三角=危险敏捷；主色定性格+限色板。

### B3. 评审与协作
- 建设性反馈：先问意图再给方案；描述影响而非指责；区分"必须改/建议/个人偏好"。
- **Paintover 会议**：评审者直接在画布涂改示范；**Dailies**：每日固定全员看稿。
- 远程：Miro/Figma + 异步录屏（Loom）；绝区零"角色设计=沟通"是组织层同趋势注脚。
- 组织共性：星铁"立项大量采访成员"、绝区零"跨部门参与"、腾讯"用研+设计师主导"——评审前置化、多元化。

### B4. 交付物
- Character brief（唯一事实源）；thumbnails/silhouette sheet（评审淘汰用）；model sheet/turnaround 三视图；callout sheet 拆解图（网易 JD 明确要求，二次元卡牌标准）；expression sheet 表情差分（日本体系强调）；key visual 立绘（日本常由角色设计师本人绘制保证一致性）。
