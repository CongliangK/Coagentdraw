# 角色设计八阶段工作表

本目录统一收录阶段一至八的工作表，按 01—08 编号；阶段一使用角色意图卡，不再在目录外单独维护模板。

人和 AI 共用一张表：按填写提示完成旁边的空白，将说明与设计记录放在一起。选择当前需要的阶段，条目不足时直接增添表行。

| 阶段 | 这一步做什么 | 工作表 |
|---|---|---|
| ① 立项定位 | 明确角色是谁、有什么吸引力、承担什么作用 | [立项定位（角色意图卡）](01_立项定位.md) |
| ② 前期调研 | 用丰富的图像与文本激活想象，形成初步角色意象 | [前期调研](02_前期调研.md) |
| ③ 创意提案 | 为同一角色提出不同的设计解法 | [创意提案](03_创意提案.md) |
| ④ 方向探索 | 用小稿比较形状、结构、明暗与配色 | [方向探索](04_方向探索.md) |
| ⑤ 方向锁定 | 选定主稿，明确必须保留与仍可调整的部分 | [方向锁定](05_方向锁定.md) |
| ⑥ 评审收敛 | 发现具体问题，修改并比较效果 | [评审收敛](06_评审收敛.md) |
| ⑦ 定稿交付 | 按用途整理能继续制作的图稿与文件 | [定稿交付](07_定稿交付.md) |
| ⑧ 最终插画 | 用画面呈现角色的行动与核心幻想 | [最终插画](08_最终插画.md) |

绘画与修改保留可编辑原稿，选定方向和完成判断由人确认。各阶段工作表均在本目录内维护；原[八阶段工作说明 v0.3](../角色设计八阶段工作规范_审核初稿.md)与[调研报告](../调研报告/README.md)保留供查阅。
