## 一、作者要求与设计锚点

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 作者要求 | 作者明确的设计要求 | |
| 角色标识 | 角色的名字或代号 | |
| 设计目的 | 用在什么上面，要起到什么效果？ | |
| 核心幻想 | 角色要为观众、玩家或读者提供怎样的幻想与想象？ | |
| 视觉重心 | 哪些服装、剪影、装备、发廓与主色块共同构成角色的核心识别形象？ | |

| 身份与行动需求 | 职业、社会与经济条件，以及代表性的活动方式 | |
| 时代与文化参照 | 服饰与器物的时代、地域文化和技术参照 | |

## 二、可见形象

**形状语言用于试拼中的分析与调整。** 当前锚点可以直接带入检索和拼贴，不必先完成整卡、抽象几何方案或独立剪影。在图像中观察圆、三角、方形等主形与辅形的方向、比例、分布和轮廓节奏，调整身体、服装与装备形成的大形。整身剪影与主体构成 → 依附结构 → 表面细节是细化时的结构依赖；形状的情绪倾向结合重心、曲直与语境判断。主体改变时，同步重看依附设计。

**核心是一组共同承担角色识别的具体视觉要素。** 多项构件协同表达同一核心命题：先写清服装大形、身体比例、关键装备、发廓与大色块怎样组合，再安排次要支撑和表面细节。

已有条件记录资料依据，初步探索方向记录设计提议；来源随格短链接。

| 维度 | 填写提示 | 已有条件（注明依据） | 初步探索方向（未定稿） |
|---|---|---|---|
| 剪影与形状语言 | 主形与辅形是什么？方向、比例、分布如何形成整身轮廓？ | | |
| 服装 | 先定主服装的类别、长度、体量、整体剪裁与开合；再展开内搭和局部结构 | | |
| 身体与比例 | 视觉年龄、体型与主导比例 | | |
| 面部与辨识特征 | 脸形、五官比例与辨识特征 | | |
| 发型与头部造型 | 主要发廓、分区、发长与束扎方式 | | |
| 武器／施法媒介 | 有无、类别、尺度、轮廓与携带方式；与整身剪影的关系 | | |
| 工具与配饰 | 核心装备的类别、尺度、轮廓与携带位置；其他配饰简写 | | |
| 配色 | 主色、辅助色、强调色的面积与位置；大色块的组合关系 | | |
| 材质与表面 | 主要材料的软硬、厚薄、光泽与粗糙度，以及主要材质对比 | | |
| 纹样与识别标记 | 纹样与徽记的位置、大小、密度及其与主服装的关系 | | |
| 神态与姿态 | 常用站姿、表情与动作特征 | | |

完整意图卡应有可想象的整身粗方案，与作者讨论主体构成及其取舍；只有当前锚点时，可直接进入[联想与前期调研](<02_联想与前期调研.md>)，用试拼补出尚未确定的形象。保留原表字段，已有资料由助手提炼，不让作者重抄；后续研究与草图继续修正方向。
