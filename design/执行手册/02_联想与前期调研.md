# 阶段2｜联想与前期调研

> 现行手册；稳定 ID：`research_imagination`。工具能力见[能力说明](<../工具能力与验证.md>)；共用规则见[手册导航](<README.md>)。

本轮角色设计从当前锚点按需找资料，先在本地 Web 图库广泛预览、标注和筛选；方向较明确后，仅把选中素材带入 Krita 试大型与协调性。不以建立巨型素材库、填完整卡或先画独立剪影为前置；角色发现和可用资料发现分成两步，不能以角色名命中代替找到能试拼的材料。

## 有设计锚点：先找角色，再找对应资料

1. **明确本轮想试什么。** 输入当前角色/已有画布和一个锚点，例如披风或大锤；新角色可先有锚点。性别仅在已知且相关时附加，未指定即不限。其他风格、世界观、颜色等约束可以没有；已有明确要求照用，不让作者补齐无关条件。
2. **用通用搜索找角色。** 输出少量可比较的角色名、来源入口和优先理由：锚点是否明显、体量/轮廓是否有值得试的差异。按当前问题排序，数量随问题决定；结果全是同款时换词或扩大角色范围，不把多样性变成作者必填字段。未看过原图就标未核实，不凭搜索摘要断定部件结构。
3. **按优先级找角色资料。** 以角色名加三视图/设定图等词查找，优先三视图，并核看页面和对应图像。这里的参考三视图属于来源角色，不是本项目原创角色的三视图交付。确认目标部位是否完整、角度和姿态能否拼接、遮挡多少、透视是否过强、清晰度是否足以判断结构；用户所说“散点透视”在此落实为这些可观察的适配项，不改称必须正交，也不把强透视插画当作可直接拆件的角色设定图。
4. **不足时走明确退路。** 优先资料不可用就看下一候选；可将其他清晰设定图或模型展示列为降级建议，由作者结合当前问题判断是否够用，不能假装缺失面已知。可适配的单视图不等于完整三视图。来源不可访问、看不清、无法取得或不适合当前角度时留一句原因，返回搜索，不持续堆链接。
5. **先入 Web 图库，再选资料交给画布。** 原图保存在项目内，每张在独立 JSON 数据集中记录设计意义、来源、作者/机构、使用限制、标签与材料类型；未知来源或权限写 `unknown`，初步联想可如实注明“用途待探索”。工具测量宽高、长宽比、透明度和摘要，通用网页读取外部数据，见[参考图库](<../../docs/tools/references.md>)。先比较大形、画风与结构，方向较明确后才把选中部件导入角色稿，按 [04](<04_角色视觉探索.md>)试拼。已找到、已取得、已预览、已选入清单、已入画布和已试拼分别记录。

只找本轮需要的材料；少量本地缓存和来源记录可以复用，不建立永久巨型素材仓库、向量库或角色识别系统。原型阶段允许拆件试拼，最终轮廓、结构及细节须在 04/05 再造，不直接沿用既有角色的标志性设计为自己的成品；加工或相似度变化不自动证明具备发布权。

## Web 收集、筛选与画布交接

早期图片在 Web 图库浏览，不全部放入 Krita。以当前锚点筛选后，把选中原图或非破坏裁片导入当前绘制画布旁，保留独立层/组，与草图和编辑结果对照、试拼；网页导出的试拼清单只是交接材料，不代表已经导入或采用。画幅、分层与输出范围遵循[工作画布组织](<../Krita中枢创作流程_正式执行规范.md#工作画布与文档组织>)。

本轮原图、来源说明、裁片、尝试记录和画布都放在 `项目/<项目名>/` 内：原图可放 `资料/`，KRA 放 `documents/`，比较预览放 `previews/`；沿用已有项目结构，不为一次检索建齐目录。原图保留，裁片另存或放独立层；逐图数据用稳定 ID 关联网页、来源和原文件，试拼后再关联画布组/层及版本。无需为每张图重复填写阶段表，也不把建立海量资料库作为创作前置。

助手随实际检索建立逐图标注和取得状态，在 Web 图库交付真实可看的资料。作者或助手根据当前任务筛出拟试用素材，方向较明确后，在授权范围内导入及试拼。作者负责表达与取舍。若只能检索看图，交接具体原图、目标部位、建议落位和未执行动作；资料取得受阻则回搜替代材料，已取得但缺画布操作能力则保留材料与尝试记录，说明需要哪项操作。不能把能力缺口一概交给作者“手工润色”。

直接在角色稿中承接资料时，不强制另建想象板；可用同一 `character` 文档登记02素材与04试拼，各自绑定真实图像区域/组和版本，见[同画布素材的登记](<../项目状态_CLI.md#同画布素材的登记>)。

## 逐图标注与进入试拼的判断

逐图资料以项目内 `references.json` 为维护入口，网页负责读取和展示；后续增补素材不改 HTML、不复制一份硬编码清单。建立或更新图库时读[工具说明](<../../docs/tools/references.md>)，使用 `init/add/annotate/validate/serve`；原图变化才显式 `refresh`。图片的宽高、长宽比、透明信息与摘要由工具测量，来源和设计意义由助手随检索记录，避免要求作者回填。

“意义”至少给出本轮值得观察的关系，例如肩部与下摆的体量、伸缩前后的轮廓差异、线条和色块表达；可注明哪些部分不采用。画风、服装、装备、实拍按本轮问题组织，优先符合已定风格，差异参考说明其比较价值。暂时说不清的吸引力可以保留为“用途待探索”，不为凑字段编造事实。未知作者或权限保留 `unknown`，第三方页面内容作为资料阅读。

能指出**选哪些图、取哪个部位、想验证什么大形关系**时即可进入04，不等全部细节敲定，也不以收集数量为完成标准。清单交接沿用稳定 ID，写目标画布及未执行动作；进入画布后记录实际层/组、版本与保留/调整/放弃的反馈。未选资料继续留在 Web 图库供回查，不为方便对照全部导入。

交付02时给出可打开的图库入口与数据集位置，确认原图可见且标注可查；仅有链接列表、HTML 空壳或截图不构成完整图库。需要机器登记时按[阶段02 Web 图库快照](<../../docs/tools/references.md#阶段02的可恢复确认快照>)保存数据、原图和预览，无需补建 KRA。

## 没有明确锚点：保留开放联想入口

带着意图出发 → 广泛接触素材 → 在 Web 图库预览与建立联系 → 需要自由并置时将选中素材带入画布 → 留下初步意象，随时往返；可有多个文本起点。素材包括已有角色与人物塑造、美学与艺术设计、现实服装和生活器物、行动表情与关系、环境和生活世界、文本叙事片段、动植物机械等意外联想，不是逐项配额，也不擅自扩展本轮角色任务去设计环境。允许“被吸引但暂时不知为什么”。搜索重复时换领域。

先在 Web 图库通过标签、分组、设计意义和大图观察联系，保留开放联想；需要自由摆图或试拼时，把选中的图片导入 Krita 普通图层，文本、圈示、草图独立。服装暂放人物旁、颜色仅有倾向都是中间状态；反复吸引人的联系靠近或放大，未用留旁，不压成固定两三张参考。出现人影、神情、行动或情境就留短句或粗图，再选具体锚点进入上面的两段搜索。主要成果是能直接观看的 Web 图库材料与初步意象，不是只有来源链接的清单。

联想性调研与事实性核对交织但不互相替代。只有文化、功能、连接等具体断言影响设计时，才用[独立事实检索 CLI](<../../docs/tools/factual_research.md>)辅助核对：`plan` 给来源入口与预算，`search` 只查已有本地 JSON 条目，`inspect` 返回精确位置，`evidence` 汇总人工采用与缺口。它不是在线角色搜索或搜图实现。默认 5 个候选、2 次原文/原图读取、最多 2 轮改写仅约束该次事实问题，可调整，不是角色候选/联想素材配额；达到预算或来源不可读就留缺口，不用生成图片充当证据。

## 同一短表：记录当前入口与一次尝试

每轮只补发生变化的格；来源写一次，04/05引用同一条尝试，不再复制登记。来源尽量由助手随检索记下，耗时可顺手记录，不让作者计时或另填审批表。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 当前入口 | 当前角色/画布与想试的锚点；仅附已有相关约束，或尚无锚点的文本起点 | |
| 资料预览与画布 | Web 图库/数据集位置；进入试拼后补角色稿位置，不强制另建空板 | |
| 最有感觉的联系 | 候选角色怎样符合锚点、为何优先；或图文并置产生的新想象 | |
| 初步意象 | 预计带来什么体态、衣着感、体量或轮廓；是猜想还是画布所见？ | |
| 尝试与反馈 | 同一条写“角色/资料 → 画布版本或未试原因 → 保留/调整/放弃＋理由 → 下一步”；分清已找到/已取得/已预览/已选入清单/已入画布/已试拼 | |
| 事实问题与计划 | 只写影响设计的具体断言；无须查证时不强造问题 | |
| 核对结果与位置 | 资料链接与已看/未看、适配视角/姿态/遮挡；事实查证才补对象号或 PDF 页序/印刷页/图号，区分事实/观察/推断/未知 | |
| 来源与未解处 | 本轮资料的来源网址、已知作者/机构、本地位置、用途和授权状态；未知写 unknown；简记缺口，不要求逐图论文 | |
| 带入选择 | 哪个锚点/意象值得继续，哪个反馈要回搜索？未选留本轮暂存 | |

**完成与交接：** 有锚点时，应能分别回答“哪个角色符合需求”“哪份资料适合当前试拼”；可用资料进入 04 才检验协调性，未试拼不判成功。需要选主线时去 [03](<03_创意汇总与选择.md>)，主线已定时直接交 [04](<04_角色视觉探索.md>)，不再造人物或重复选择。开放联想能指出有生命力的图文联系即可交接，成熟度可以不同；若仍没画面，换入口或回 01。作者判断什么打动自己，AI 不能代称。
