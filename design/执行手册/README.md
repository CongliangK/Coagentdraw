# Krita 中枢八阶段执行手册

唯一现行总纲：[正式执行规范](<../Krita中枢创作流程_正式执行规范.md>)。人和 AI 共用各阶段表格，记录画布位置与短句即可，不重复抄写，不虚构填满。普通表采用“项目—填写提示—填写内容”；[阶段一完整意图卡](<01_文本创作起点.md>)的外观部分另将已有条件与初步探索方向分列。表格不是成果或批准凭据。

## AI 加载与填表约定

先加载 [coagentdraw-design 技能](<../SKILL.md>)，再实际读取本次阶段正文；没有技能调用能力时直接读该入口，不只凭导航摘要执行。

- 作者选定的模板是交付结构：保留原栏目、字段、顺序和填写提示，按各列职责作答；不把表格换成长文，也不擅自裁成摘要表。作者要求改模板时同步更新规则，不把旧结构固化为禁令。
- 每格简洁填写；资料事实与设计提议分开，未知注明缺口，不编造成已确认设定。受委托设计时可以且应当提出具体外观方向，不能用整表待确认代替设计。来源在格内短链接即可。
- 阶段一只填“作者要求与设计锚点、可见形象”两部分；不附起点、分支、状态、表达边界或调研交接表。作者要求集中记录，核心幻想只说明一次，来源在对应格内短链接，不另加同义关键词表或总结句。
- 填写提示简短直问：角色标识是名字或代号；设计目的是用在什么上面、起到什么效果；表现风格用专业名称。提示只保留填写所需的信息。
- 当前锚点可直接进入02搜索角色与资料、04试拼；不要求先填完整卡、先画独立剪影或建立素材库。主形与辅形的方向、比例和分布用于试拼分析与调整，仍讨论整身粗方案，再细化依附结构；主体改变时重看依附设计。“视觉重心”写具体核心识别组合，如服装大形、身体比例、关键装备、发廓与主色块，多项要素共同表达同一命题。详细角色操作仅见02/04/05。
- 作者要求少写，先去除模板外扩写；作者给出核心关键词，校准内容重点但不删除字段。当前任务只做角色形象时，不额外设计环境、场景或剧情。
- 交付前自己核对模板、作者重点与本轮范围；不向作者新增表单或逐项审批。通用流程与单个项目偏好分开。

## 八阶段入口

| 阶段 | 画布动作与交接产物 | 手册 |
|---|---|---|
| 01 角色设计意图卡 | 明确作者要求、核心幻想、设计锚点与可见形象方向 | [打开](<01_文本创作起点.md>) |
| 02 联想与前期调研 | 锚点→角色→对应三视图/设定资料；可看材料与本轮尝试记录 | [打开](<02_联想与前期调研.md>) |
| 03 创意汇总与选择 | 并排图文创意比较；跨起点选择与未选去向 | [打开](<03_创意汇总与选择.md>) |
| 04 角色视觉探索 | 当前画布拼贴大型、协调性反馈、结构线稿与基础色试验 | [打开](<04_角色视觉探索.md>) |
| 05 角色方案收敛 | 保留原型设计决定、原创线稿再造、上色、改图与复看 | [打开](<05_角色方案收敛.md>) |
| 06 三视图设定与核对 | 建立共同基准、展开侧背、逐件核对；一致正侧背 | [打开](<06_三视图设定与核对.md>) |
| 07 插画方案探索 | 本幅表达任务；三轮比较构图动作、补结构空间、形成结构与光色确认稿 | [打开](<07_插画方案探索.md>) |
| 08 插画制作与交付 | 四轮推进：8A＋B 整幅底画、8C＋D 局部细节、8E 统一、8F＋G 收尾；最终图、有效可编辑源与清单 | [打开](<08_插画制作与交付.md>) |

07/08 的轮次是日常工作组织，可以合并、往返，不增加宏观阶段或审批链。作者持续统筹当前主稿；表达可以是事件、状态、情绪、关系或形象气质。具体操作、六项短画改任务、失败出口与回退均以 [07](<07_插画方案探索.md>) / [08](<08_插画制作与交付.md>) 为准，不另抄一套操作表。

## 共用视觉与安全规则

- 图像判断回到 Krita；引用记录文档、本地 KRA、组/层或画布区域及预览版本，不能只写“图3”。参考、候选、主稿与诊断分身份，原图保留。
- 角色源的线稿和基础色继续保留；新镜头需自己的结构与制作依据。需要独立调整的内容应有真实作用于当前画面的层或蒙版，旧层被不透明 AI 图盖住不算有效分层；分区/蒙版也不会自动还原生成图语义。按画风决定是否终稿清线。新结果先候选，作者接受并实际采用后才是下一轮基底；叠加不能冒充擦除旧线的替换。
- 对比提供同尺度全图和局部；缩小只用显示缩放或观察副本，不擅改作者源 KRA、画幅或交付尺寸。原稿、旧分支与未选候选保留；相互影响的局部不在旧基底各自修完后强拼。可见性恢复遇人工变动先查冲突。
- 目标不清、源改变、无有效选区/映射不回填；无选区不默认为整图，超时未知先查结果不盲重试。保存/覆盖须在授权内。
- 本地 KRA 是可编辑源，PNG 是预览/交换；保存重开与最终导出都需实际检查。工作文件与不变批准快照分开；批准绑定版本、范围与真实人类来源。
- 项目关注阶段、模型执行、人类艺术验收分别记录。A 离线、B 实机、C 真实创作分别给证据，空表与测试成功不等于作品通过。
- 原生参考图可人工辅助，但画布投影不一定含画布外参考，不能冒称 AI 已看见。默认共享板用普通层/组，素材分批分页，不取消资源保护。

工具边界见 [ComfyUI 输入与蒙版](<../../comfyui/README.md>)：普通 edit 非几何锁定，localedit 无额外独立角色/Pose/Depth 输入；GUI 画改须由实际具备能力且获授权的执行者完成，现有 CLI 不提供通用笔刷、变形或滤镜。compare 只记录决定，review 不能替代作者艺术判断。

PR-02已提供新状态索引/按文档角色组层，旧状态只读保留旧语义；真实画布与改图自动化仍见[改造跟踪](<../Krita中枢改造跟踪.md>)，不能以索引或空组代替成果。
