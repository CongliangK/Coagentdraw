# 角色设计八阶段工作说明

> 审核初稿 · v0.3

这套流程从角色意图出发，经过探索和收敛，形成角色设计，再通过插画呈现角色的魅力。

**每个阶段都可以由人、AI 或两者共同完成。手绘、生成、编辑、拼贴都是实现方式；阶段以工作成果验收。**

## 流程总览

| 阶段 | 最重要的事情 | 核心产出 |
|---|---|---|
| ① 立项定位 | 明确角色要表达什么 | 角色意图卡 |
| ② 前期调研 | 找到支撑设计的参考与依据 | 注释参考板 |
| ③ 创意提案 | 提出不同的概念解法 | 概念提案 |
| ④ 方向探索 | 把概念变成可比较的视觉方案 | 小稿探索板 |
| ⑤ 方向锁定 | 选定主方向，确立设计支柱 | 方向说明与选定稿 |
| ⑥ 评审收敛 | 解决设计问题，使角色完整自洽 | 完整角色设计稿 |
| ⑦ 定稿与交付 | 把设计整理成可继续制作的依据 | 角色设计包 |
| ⑧ 最终插画 | 用画面放大角色的核心幻想 | 最终插画与源文件 |

## ① 立项定位：角色要表达什么？

### 核心

先明确角色带来的体验，再决定外观。「核心幻想」是观众想成为谁，或想通过这个角色感受到什么。

### 工作：写一张三层意图卡

1. **主题（Theme）**：角色属于什么世界、文化与时代，在其中是什么身份？
2. **幻想（Fantasy）**：用一句话说明角色的吸引力。如调研中的烬：「舞台上的完美主义杀人艺术家」。
3. **功能（Function）**：角色做什么、如何行动，在玩法或叙事中起什么作用？
4. **表达词与约束**：选出几个能指导画面的词，并解释其含义；列出必须体现的特征。比如「仪式感」意味着动作、道具与装饰具有秩序和重复关系。
5. **用途与差异**：明确面向谁、最终交付什么，以及与同类角色相比最值得保留的新意。

### 验收

读完意图卡，能清楚回答：**这个角色是谁、有什么吸引力、与同类有什么不同？**

主题、幻想与功能相互支持，表达词可以转化为视觉选择。

### 产出与衔接

使用[角色意图卡模板](<执行手册/01_立项定位.md>)填表，交付角色意图卡。第二阶段按主题、幻想和功能分别寻找参考。

## ② 前期调研：什么能支撑这个设计？

### 核心

建立参照系，把抽象意图转化为可用的设计素材和依据。

### 工作：按问题组织参考

1. **现实基础**：研究文化、时代、职业、服装、材料和工具，回答「它从哪里来、如何使用」。采用 FZD 的思路，以真实参考铺底，再加入有辨识度的变化。
2. **功能依据**：观察穿戴、持握、移动和携带方式。例如远行者如何分配负重，剑客拔剑时衣袖与刀鞘如何配合。
3. **视觉表达**：收集形状、比例、剪裁、色彩与气质参考，选出 2—3 张主参考，其余按问题归类。
4. **同类比较**：列出同类角色常用的剪影、武器与服饰符号，找到可用的共性与可突破的惯例。
5. **提炼启示**：每张主要参考写三项：「看到什么 → 为什么适合角色 → 准备怎样转化」。比如借鉴防护服的层叠结构，再将其转化为角色的外衣与护具关系。

### 验收

参考板能回答：**为什么采用这种服装结构、材料或形状语言？**

主参考明确，现实基础、功能与美术表达都有依据，并且能提炼出进入提案的设计想法。

### 产出与衔接

交付注释参考板与设计启示。第三阶段将这些素材组合成不同的概念解法。

## ③ 创意提案：这个角色可以怎样成立？

### 核心

先提出设计解法，再用粗图讲清楚。提案的重点是「为什么这样设计」。

### 工作：从关键词推导到提案卡

1. **拆解关键词**：把意图卡中的词转换为可观察特征。例如「沉稳」可以探索低重心、宽厚体块、缓慢动作；「敏捷」可以探索修长比例、轻量穿戴、明确的运动方向。
2. **追问关键矛盾**：围绕身份或限制问「他如何做到？」调研中的盲人剑客，通过追问感知方式，引出了以竹为载体的新概念。
3. **建立视觉隐喻**：寻找能同时表达身份、功能与性格的母题。调研中奥恩的羊角，把公羊撞击与铁匠锤击联系起来，使美术与功能互相支持。
4. **组合不同解法**：用「文化/时代 + 功能 + 幻想载体」组合至少三个候选。可以从叙事推外观，也可以从一个有趣的动作或视觉形象反推身份与功能。
5. **拉开发散范围**：尝试一个常规方向、一个反转方向、一个极端方向。卡住时先列俗套或糟糕解法，再问「反过来会怎样」。
6. **做成提案卡**：每个方向用一句话、几个关键词、一张粗图和一段理由呈现；最后比较并选择进入探索的候选。

#### 提案卡格式

| 内容 | 要写清楚什么 |
|---|---|
| 一句话概念 | 这个方向最吸引人的想法 |
| 关键矛盾与解法 | 角色面对什么问题，如何解决 |
| 视觉母题 | 哪个形状、物件或动作承载核心幻想 |
| 粗略示意 | 用草图、拼贴或生成图说明整体想象 |
| 后续验证 | 下一阶段要试的比例、剪影、剪裁或道具关系 |

### 验收

几个方向在身份表达、功能解法或视觉隐喻上有实质差异。每个候选都能说明：**如何实现核心幻想，最值得画出来验证的地方是什么？**

### 产出与衔接

交付概念提案卡与候选方向。第四阶段围绕每张卡中的具体问题做视觉实验。

## ④ 方向探索：哪种视觉解法最有效？

### 核心

先解决大形，再解决内部结构与色彩。用低成本小稿比较不同解法。

### 工作：按四轮展开

#### 第一轮：纯黑剪影——只看外轮廓

- 在同一尺度、相近视角与姿态下，用纯黑形块搭建角色；从身体、服装、道具三个大块开始。
- 改变头身比、肩胯宽度、躯干与四肢长度、重心、道具体量与位置。先把比例拉开，再考虑回收。
- 探索主导形状：圆润、方厚、尖锐或混合；让身体、服装和道具的形状语言互相呼应。
- 检查负形，即手臂与躯干、双腿、道具与身体之间的空隙。调整姿态或道具位置，让关键轮廓分开。
- 做一板约 8—20 个小稿，缩小并排比较：哪个最容易辨认，哪个最能体现核心幻想？留下两三个有潜力的剪影。

手绘时直接画黑块；已有图像可提取主体并填黑，再用画改或编辑改变外轮廓。

#### 第二轮：服装剪裁与内部结构——大形如何组成

在候选剪影上画简化结构线，按以下维度做变体：

| 维度 | 具体怎样探索 |
|---|---|
| 外衣体量 | 长/短、宽/窄、贴身/宽松，观察对整体比例的影响 |
| 分割与开口 | 领口、肩线、腰线、袖口、下摆、开衩的位置与方向 |
| 层叠关系 | 内衣、外衣、护具、披挂怎样覆盖、连接与收束 |
| 对称关系 | 对称表达秩序，不对称突出动作、职业或关键装备 |
| 材料行为 | 硬质如何支撑，软布如何垂落，活动部位如何折叠 |
| 功能关系 | 衣物如何穿脱、固定，是否支持行走、持械与角色动作 |

将文化元素转成轮廓、开口、层叠和剪裁关系。参考调研中的「古代元素 + 现代剪裁」，让文化特征进入服装结构。衣褶顺着受力和材质组织，并呼应大的形状方向。

做一张简化动作稿，检查伸臂、转身、拔剑等关键动作下，服装与道具是否配合。

#### 第三轮：明暗与配色——建立读取层级

- 先用黑、灰、白划分大色块，比较脸部、躯干、衣物和道具的主次关系。
- 再做少量限色配色，安排主色、辅助色与强调色，比较它们对身份和情绪的影响。
- 把最重要的对比放在希望观众注意的地方，如脸、持械部位或核心道具。借鉴 TF2 的读取层级，先读整体身份，再读职业特征，最后读关键装备。
- 放在预期背景上看：剪影和主色是否能从环境中分离？

#### 第四轮：远看与近看——选出候选

远看缩略图和剪影，检查整体识别；近看服装、道具与材料，检查细节逻辑。将候选放在同一板上比较，写出各自优势，再围绕最有价值的特征做一轮变体。

### 验收

- 纯黑状态下，候选的比例与轮廓有清楚差异，关键道具和动作关系可读。
- 服装剪裁支持角色身份与活动方式，并强化整体形状。
- 明暗、主色和强调色有明确层级。
- 能具体说明：**哪一稿更能表达角色，优势来自哪些形状、结构或色彩关系？**

### 产出与衔接

交付剪影板、剪裁与结构变体、配色比较和候选短名单。第五阶段从中确定主方向。

## ⑤ 方向锁定：接下来围绕什么深入？

### 核心

把选择理由转化为设计支柱，让后续细化有明确依据。

### 工作：做一次最终方向提案

1. 将候选放在同一尺度下，对照核心幻想、识别度、功能与风格比较。
2. 选择主方向，标出最值得保留的比例、轮廓、剪裁、道具与色彩关系。
3. 提炼两三条「意图 → 视觉特征」的设计支柱。例如：「沉稳守护者 → 低重心、宽厚主形」；「远行经历 → 有层次的携带结构与使用痕迹」。
4. 列出已确定特征和待深化细节，安排下一轮制作重点。
5. 如已有项目标杆角色，将选定稿与其并排，检查世界观、夸张程度和细节密度是否协调。

### 验收

主方向明确，设计支柱可以直接用于判断后续修改。接手者能回答：**哪些特征定义了这个角色，接下来重点完善什么？**

### 产出与衔接

交付选定稿与方向说明。第六阶段围绕设计支柱细化和修订。

## ⑥ 评审收敛：设计是否完整、自洽？

### 核心

先修影响整体的设计问题，再完善细节。评审与修改形成循环。

### 工作：三轮检查，加一次画改对比

| 轮次 | 检查什么 | 怎样修改 |
|---|---|---|
| 结构草稿 | 比例、重心、动作，身体与服装的空间关系 | 改大形、调整连接和遮挡；用简化动作验证 |
| 设计细化 | 剪裁、道具构造、穿戴与持握，纹样和细节主次 | 用局部拆解说明结构，删减干扰识别的细节 |
| 色彩材质 | 色块层级、材料差异、使用痕迹与角色气质 | 调整配色、边缘、反光和纹理，强化视觉焦点 |

提出反馈时，先确认设计意图，再写「这里是什么 → 对表达有什么影响 → 希望改成什么」。把反馈分为必须改、建议与个人偏好。

关键问题直接在画面上做 paintover：画出轮廓、体块或色块的调整示意，再据此完成修改。将修改前后并排看，并重读设计支柱与关键提醒清单。

### 验收

角色的结构、物件关系、色彩与材质形成统一整体。关键问题有可见的修改结果。

对照第五阶段检查：**核心特征是否更清楚，细节是否强化了角色的身份和幻想？**

### 产出与衔接

交付完整角色设计稿与关键说明。第七阶段整理成可供接手的设计包。

## ⑦ 定稿与交付：别人能否据此继续制作？

### 核心

把角色设计的结构与表达讲清楚。

### 工作：按下游问题组织设定页

- **概念主图**：展示整体比例、主配色、关键剪裁和身份特征。
- **辅助视图**：按制作需要补正、侧、背或局部视图；用头顶、肩、腰、膝等水平线对齐比例，核对同一构件的位置与尺寸。
- **细节拆解（Callout）**：放大武器、连接件、服装层叠和材质，标明怎样固定、打开、持握或使用。
- **表情与姿态**：用少量表情或动作体现性格，并说明设计在运动中的变化。
- **设计说明与源文件**：标出必须保持的特征，整理图层，使角色、道具和说明便于继续编辑。

### 验收

主图、辅助图与说明一致。接手者仅根据设计包，能回答：**角色长什么样、关键结构如何连接、插画中要保持哪些特征？** 源文件能够继续编辑。

### 产出与衔接

交付角色设计包。第八阶段据此展开情境、动作与画面表达。

## ⑧ 最终插画：怎样让观众感受到角色的魅力？

### 核心

通过动作、情境、构图与光色，把角色幻想转化为鲜明的观看体验。

### 工作：从画面事件到成品

1. **写画面事件**：用一句话说明角色正在做什么、处于什么情绪、观众站在哪里；选择最能表现身份与性格的瞬间。
2. **画构图小稿**：用简化形块探索至少三种镜头和主体关系。比较远近、俯仰、姿态动态线、环境与道具的叙事作用。
3. **做画面裁切**：按最终画幅移动裁切框，检查头、手、关键道具和动作是否仍清楚；比较全身、半身与近景哪种更有表现力，处理关节截断和轮廓贴边等问题。需要不同画幅时，同步试裁切。
4. **组织明暗**：用少量灰阶安排主体、背景和焦点；缩小看是否先读到最重要的动作或表情。
5. **做色稿**：比较光源、冷暖和色彩情绪。让角色主色与环境协调，同时保持主体分离。
6. **完成细节**：围绕选定构图深化结构、光照与材料，把最丰富的细节放在焦点附近，再整理成品和源文件。

### 验收

分三次检查：

| 检查点 | 核心要求 |
|---|---|
| 构图与叙事 | 动作、镜头和主体关系清楚，裁切保留关键表达，情境体现角色魅力 |
| 明暗与色彩 | 缩略图中焦点明确，层次清晰，光色强化画面情绪 |
| 最终完成 | 角色特征一致，结构与空间成立，细节服务整体，满足交付规格 |

最终回答：**这张画是否让观众更鲜明地感受到第一阶段确定的核心幻想？**

### 产出与衔接

交付最终插画与可编辑源文件，完成从角色意图到艺术表达的闭环。

## 阶段之间如何协作

每一步把产出交给下一步，并附一句说明：**已确定什么，接下来要解决什么。**

验收围绕本阶段的核心问题讨论。问题在当前阶段就继续修订；问题来自前面的设计判断，就回到对应阶段调整。

**明确意图 → 建立依据 → 提出想法 → 视觉验证 → 选定方向 → 完善设计 → 清楚交付 → 实现艺术表达。**
