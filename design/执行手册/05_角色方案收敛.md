# 阶段5｜角色方案收敛

> 现行手册；稳定 ID：`character_resolution`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

合并旧方向锁定与评审收敛：选主稿 → 提炼保持要点 → 圈出问题 → 实际改图 → 同尺度前后与全图复看 → 作者决定。打开同一 Krita 角色设计稿，保留粗稿，清线、基础色和修改候选分开。必要时对照标杆的夸张程度、形状语言和细节密度，不用总分抵消结构与功能问题。

修改记录区分必须改、建议、个人偏好；写明意图、位置、影响与预期改善。替换错误线条须有能消除旧形的独立替换分支，透明叠层不能擦掉底下旧线。不安全时放独立候选文档，不能逼作者承担全部手绘。拒绝恢复原稿，回看关键动作与身份特征；核心方向不成立可回探索重选。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 主稿 | 引用所选候选及其线稿/平涂组 | |
| 保留要点 | 哪些比例、轮廓、衣物、颜色分区和道具决定角色身份？ | |
| 阻碍问题 | 直接圈出图上位置，不只写“还不够高级” | |
| 实际修改 | 对应修改前后图层或版本；记录是否采用 | |
| 清晰线稿 | 领口、肩线、腰线、穿插、装备连接是否说得清？ | |
| 基础配色 | 主色/辅助/强调色在具体区域如何分布？ | |
| 尚需侧背面解决 | 标出正面无法决定的结构，不由 AI 假装已知 | |
| 作者确认 | 确认当前角色主方案；不等于确认插画构图 | |

**完成与交接：** 清晰主视图线稿和平涂成立，关键问题真实修订或明确处理，足以展开三视图。确实无须修改可记本轮无修改，但端到端真实试用至少一次实际修订。作者确认角色主方案不等于确认插画；侧背发现问题可回修并注明影响。
