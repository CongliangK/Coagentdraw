# 阶段一｜立项定位（角色意图卡）

填写目标：明确 **角色是谁、有什么吸引力、承担什么作用、与同类有什么不同**。

人和 AI 使用同一张表。按「基础信息 → 核心判断 → 调研问题」填写；尚未确定的内容写入调研问题。

## 一、基础信息：这个任务与角色是什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色名称 / 代号 | 用于识别本次设计，可用临时代号 | |
| 使用场景 | 用于什么项目或作品？如游戏角色、故事人物、宣传插画 | |
| 目标观众 | 为谁设计？他们对这类角色有什么期待？ | |
| 最终交付 | 需要角色设定、立绘、情境插画或哪些组合？注明主要画幅与观看场景 | |
| 世界与时代 | 角色生活在什么世界、文化和技术条件下？ | |
| 身份与处境 | 职业、阵营、社会位置，以及当前面临的处境 | |
| 性格与动机 | 最主要的性格是什么？想得到什么？为何行动？ | |
| 行动方式 | 如何战斗、工作、生活或与他人互动？写代表性行为 | |
| 已有条件 | 已有故事、设定、参考或项目风格中，哪些内容需要沿用？ | |

## 二、核心判断：我们决定表达什么？

| 判断项 | 填写提示 | 填写内容 |
|---|---|---|
| 主题 Theme | 用一句话定义角色在世界中的位置与主题；可用「文化/时代 + 身份 + 处境」组织 | |
| 核心幻想 Fantasy | 观众想成为怎样的人，或从角色身上感受到什么？用一句话概括其吸引力 | |
| 功能 Function | 角色在玩法、叙事或画面中承担什么作用？这一作用要求角色具备什么能力或行为？ | |
| 独特之处 | 对比同类，最值得保留的新意是什么？可来自性格、处境、行动方式或设计矛盾 | |
| 最重要的表达 | 观众第一眼最应该读到什么？进一步观看时，希望发现什么？ | |
| 关键矛盾 | 哪两个特征之间的张力最有创作价值？如柔弱外表与强大力量、庄严身份与叛逆行为 | |
| 必须体现 | 哪些身份、功能或表达要求必须进入设计？ | |
| 需要避开的方向 | 哪些气质、同类套路或设计选择与本角色意图不符？ | |
| 取舍优先级 | 当要求冲突时优先保留什么？如身份识别、功能可信度、幻想表达、美型或风格统一 | |

### 关键表达词：将意图连接到视觉探索

填写 3—5 个关键词。每个词都说明在本角色中的含义，以及可以从哪些视觉维度探索。

| 关键词 | 在本角色中的具体含义 | 可探索的视觉方向 |
|---|---|---|
| | | |
| | | |
| | | |
| | | |
| | | |

视觉方向可以是比例、重心、形状、动作、服装剪裁、道具或色彩。例如：「仪式感 → 行为讲究秩序与重复 → 探索重复构件、整齐层叠与有节奏的动作」。此处提出探索线索，具体方案在后续阶段展开。

### 一句话角色意图

| 项目 | 填写内容 |
|---|---|
| 综合表述 | 一个处于【世界与处境】的【身份】，以【性格与行动方式】承担【功能】，让观众感受到【核心幻想】；其独特之处是【差异点】。 |

## 三、交给第二阶段：具体需要研究什么？

把本卡中的未知信息与设计问题转成调研任务，交给[前期调研](<../执行手册/02_前期调研.md>)。

| 类别 | 具体问题 | 要寻找的参考或依据 |
|---|---|---|
| 主题与文化 | | |
| 身份与功能 | | |
| 气质与视觉表达 | | |
| 同类与差异 | | |

填写时把「找服装参考」细化为可回答的问题，例如：「这种职业如何携带工具，哪些穿戴结构能体现其身份？」

# 阶段二｜前期调研

填写目标：找到支撑角色设计的参考，并说清楚准备怎样使用。

人和 AI 使用同一张表。带着[角色意图卡](<../执行手册/01_立项定位.md>)中的未知，按「研究问题 → 参考与转化 → 设计依据」填写。

## 一、研究问题：现在需要弄清楚什么？

| 研究方向 | 填写提示 | 要回答的问题 |
|---|---|---|
| 主题与文化 | 哪些时代、文化或身份信息会影响设计？先查什么，才能避免只借用表面符号？ | |
| 身份与功能 | 角色如何穿戴、持握、移动或携带工具？哪一处结构需要真实依据？ | |
| 气质与视觉表达 | 要用哪些比例、形状、剪裁、材料或色彩表达角色？哪些还没有把握？ | |
| 同类与差异 | 同类角色常用什么表达？哪些共性有用，哪些惯例准备突破？ | |

## 二、参考与转化：看到什么，准备怎样用？

每条关键参考填写一组；只保留能回答上述问题的材料。搜索时把对象、具体结构或动作组合成关键词，再核对原始出处。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 对应问题 | 这条参考回答上表哪一个问题？ | |
| 来源与使用限制 | 记录作者或机构、标题、原始链接与图片位置；注明已知使用限制，授权不明时不当作可自由转载素材 | |
| 看到什么 | 写可观察的形状、连接、材料或动作关系；来源没有说明的内容标为推测 | |
| 为什么适合 | 它怎样支持本角色的身份、功能或核心幻想？ | |
| 准备怎样转化 | 保留哪种结构或关系，改变哪些比例、组合或用途，使它成为本角色的设计？ | |
| 尚待验证 | 哪个判断还缺依据？需要继续查找，还是交给画稿验证？ | |

## 三、设计依据：带着什么进入提案？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 主参考 | 选出最能支撑方向的 2—3 条参考，写明各自负责解决什么；补充参考按问题归类 | |
| 注释参考板 | 将主参考与结构标注放在一起，标明来源及转化想法；填写板图位置，也可直接用本页记录对应原图 | |
| 设计启示 | 写下值得进入提案的形状、结构、动作或组合关系，以及它们来自哪条依据 | |
| 完成判断 | 核心选择能否说清来源、适用理由和转化方法？若仍只是好看的图片，回到第二部分补判断 | |
| 下一步 | 将可用想法和待验证问题交给[创意提案](<../执行手册/03_创意提案.md>)；若问题本身不清楚，先回意图卡收窄目标 | |

# 阶段三｜创意提案

填写目标：围绕同一个角色意图，提出有实质区别的设计解法。

人和 AI 使用同一张表。按「共同问题 → 候选方案 → 比较与选择」填写；先讲清楚想法，再用粗图表达。

## 一、共同问题：这些方案都要解决什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色意图 | 引用[意图卡](<../执行手册/01_立项定位.md>)，点明本轮最重要的身份、核心幻想与功能，不重新设定另一名角色 | |
| 关键矛盾 | 哪两个要求之间的张力值得转成设计？需要怎样的解法才能同时成立？ | |
| 共同依据与限制 | 从[调研](<../执行手册/02_前期调研.md>)中选用哪些依据？所有候选必须保留什么、避开什么？ | |

## 二、候选方案：这个想法怎样成立？

为每个方向填写一组。先提出 2—3 个不同解法，区别应落在功能、结构或表达方式，不能只换装饰和颜色。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 方案名称与一句话概念 | 用短句说清这个方向最吸引人的想法 | |
| 关键解法 | 角色怎样行动或使用装备来解决上述矛盾？ | |
| 视觉母题 | 用什么形状、物件或动作承载核心幻想？说明与身份、功能的联系 | |
| 整体想象 | 主要比例、轮廓、服装与道具关系是什么？把抽象表达词落到可画的特征 | |
| 粗略示意 | 用草图、拼贴或生成图表达整体，填写图的位置；未画的写“待画”，不假装已有视觉证据 | |
| 成立理由 | 这一方案如何实现角色意图？说明借用了哪条参考、做了什么转化 | |
| 最值得验证的地方 | 写出一个具体风险，以及下一阶段画什么才能判断它是否成立 | |

## 三、比较与选择：哪些想法值得继续画？

把候选并排看，使用相同的角色意图比较。每行一个方案，按需增减。

| 候选方案 | 与其他方案的核心差异 | 保留或放下的理由 | 下一步要画什么 |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 完成判断 | 候选是否具有不同的解法，并能说明各自的吸引力与待验证问题？若只有换色、换饰品，回第二部分重新发散 | |
| 进入探索的候选 | 选出值得继续的方向，带着具体问题进入[方向探索](<../执行手册/04_方向探索.md>)；此时保留比较空间，不急于锁定最终稿 | |
| 需要回退的情况 | 若方案违背角色意图，回第一部分；若关键结构缺依据，回调研补充后再提案 | |

# 阶段四｜方向探索表

填写目标：把概念变成可比较的小稿，找出 **哪些形状、结构与色彩关系最能表达角色**。

人和 AI 使用同一张表。按「探索问题 → 画出变体 → 比较候选」填写；新稿另存或放在新图层，保留原稿。填写内容可附图或写图稿位置。

## 一、探索问题：这轮要看清什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 承接提案 | 从[创意提案](<../执行手册/03_创意提案.md>)选出要画的方向，注明最值得验证的想法 | |
| 本轮问题 | 对照[角色意图](<../执行手册/01_立项定位.md>)，希望哪种感受更清楚？准备改变什么来检验？ | |
| 比较条件 | 统一展示高度、背景、视角和相近姿态；保留各案自身比例。案内比较尽量一次只改一组变量，另做姿态探索 | |

## 二、视觉实验：怎样把差异画出来？

先用低成本小稿比较至少两个明显不同的方向，再展开有潜力的候选。每项记录「改了什么、看到了什么」，附对应图稿；只把已有图填黑还不算新的造型探索。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 剪影：比例与重心 | 用纯黑画身体、服装、道具三个大块；拉开头身比、肩胯宽、四肢长度、重心与道具体量，比较角色气质 | |
| 剪影：形状与负形 | 改圆、方、尖等主导形状及道具位置；检查手臂与躯干、双腿、道具与身体之间的空隙，缩小看轮廓是否分开 | |
| 结构：剪裁与层叠 | 在候选剪影上画领口、肩线、腰线、开衩和层叠关系；比较长短、宽窄、对称变化怎样强化身份与大形 | |
| 结构：材料与连接 | 标出软布垂落、硬件支撑、穿脱开口和固定位置；画不清的连接补局部，不用装饰遮住结构问题 | |
| 结构：动作功能 | 画一个代表性动作，检查持握、取放、关节和衣物活动空间；圈出冲突，改后用同一动作复查 | |
| 明暗：读取顺序 | 固定结构，先用黑、灰、白分大块，比较焦点位置与面积；缩小看，是否先注意到最重要的部位？ | |
| 配色：身份与情绪 | 在灰阶关系上试少量主色、辅助色和强调色；放到预期背景中比较，再去色看主次是否仍清楚 | |

## 三、候选比较：哪些值得继续？

把候选以相近完成度并排。远看整体识别，近看结构与材料；依据意图说明优势与代价，不用细节多少或总分代替判断。

| 候选与图稿位置 | 最有效的特征与原因 | 不足或尚未验证的问题 | 保留、补试或暂停及理由 |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 完成检查 | 对真实小稿指出候选的具体差异，确认结构、动作、明暗、配色和远近阅读有对应图；未画或未测的明确标出 | |
| 下一次实验 | 哪个未知最影响选择？写下一步要改什么、看什么；若各案都无法表达意图，回第三阶段重想解法 | |
| 交给第五阶段 | 附候选小稿和比较结论，进入[方向锁定](<../执行手册/05_方向锁定.md>)。填表不等于作品通过；真人评阅未做则记待评阅 | |

# 阶段五｜方向锁定表

填写目标：选定一个主方向，明确 **为什么选它、哪些特征要保留、哪些地方还可以改变**。

人和 AI 使用同一张表。按「比较与选择 → 设计支柱 → 下一轮重点」填写；选择依据来自真实候选图，最终取舍由设计者确认。

## 一、比较与选择：我们决定深入哪一稿？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 比较依据 | 附[第四阶段](<../执行手册/04_方向探索.md>)候选图，重读[角色意图](<../执行手册/01_立项定位.md>)中的优先级；缺关键动作或配色验证时先补图 | |
| 并排条件 | 统一展示高度、背景、相近视角与完成度；先看剪影与大色块，再看内部结构，不把精修程度当成方案优势 | |

| 比较项 | 填写提示 | 各候选的差异与判断 |
|---|---|---|
| 角色幻想 | 哪一稿最能让人感到角色的吸引力？指出画面上起作用的特征 | |
| 比例与轮廓 | 比较体量、重心、关键间隙和道具关系；缩小时哪个更容易辨认，为什么？ | |
| 功能关系 | 比较穿戴、持握和代表动作是否成立；哪一案更支持角色的行动方式？ | |
| 色彩与细节 | 比较大色块、焦点与细节密度；能否突出身份、保持主次，有没有过多装饰抢走注意？ | |
| 风格协调 | 有项目标杆时并排看夸张程度、形状语言与细节密度，注明来源；没有时写本角色要遵循的风格取向 | |

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 主方向与理由 | 明确选定一稿并附图，按意图优先级说明理由；审美偏好可以成为理由，但要说清喜欢什么 | |
| 接受的取舍 | 选它会失去哪一案的什么优势？为什么仍值得？必须满足的功能与表达要求不能靠总分抵消 | |
| 其他方案 | 保留未选稿及暂不采用的原因；若想借用其中的特征，写清用途与冲突，先补比较稿再决定 | |

## 二、设计支柱：哪些特征定义了这个角色？

提炼 2—3 条「意图 → 视觉特征」，在选定稿上标出位置。只写能指导修改的要点；后续评审用这些要点解释保留或修改的理由。

| 要表达的意图 | 对应视觉特征与图上位置 | 必须保持的关系及理由 | 可以调整的范围 |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

## 三、下一轮重点：继续完善什么，何时重新选择？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 优先完善 | 写下一轮最重要的 1—3 个问题，以及希望看到的改善；分清未解的设计问题与可自由尝试的细节 | |
| 重新打开方向 | 写什么情况会改变本次选择：动作不成立、用途改变、与意图冲突或审美取向改变；说明影响哪条支柱，保留旧稿，补图后重新决定 | |
| 完成检查 | 对照真实选定稿，能否清楚说出必须保留、可以修改和下一步重点？尚未确定主方向或关键依据不足，回第四阶段补试 | |
| 接手者复述 | 请实际接手者说出以上三点，记录误解并修正说明；没有真人评阅就写待评阅，不把填完表当作已验收 | |
| 交给第六阶段 | 带选定稿、设计支柱及未解问题进入[评审收敛](<../执行手册/06_评审收敛.md>)；未确认的选择明确写暂选 | |

# 阶段六｜评审收敛

填写目标：把影响角色表达的问题改到画面上，确认 **改了哪里、是否更好、保留还是回退**。

人和 AI 使用同一张表。按「检查问题 → 画改 → 前后复核」填写；一次集中解决一个主要问题，未看图或未实际操作的内容注明待验证。

## 一、当前设计哪里还不成立？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 已定目标 | 对照[角色意图卡](<../执行手册/01_立项定位.md>)与[方向锁定](<../执行手册/05_方向锁定.md>)，打开主稿；这轮要强化什么，哪些特征必须保留？ | |
| 结构草稿 | 检查比例、重心、动作，以及身体与衣物、装备的连接和遮挡；必要时补简化动作图 | |
| 设计细化 | 检查剪裁、穿戴、持握和构造是否说得通；哪些细节妨碍身份识别或抢走焦点？ | |
| 色彩材质 | 检查色块主次、材质差异和角色气质；缩小画面时，重点是否仍清楚？ | |

## 二、这次具体怎样改？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 本轮问题 | 写「要表达的意图 → 图上位置与观察 → 对表达的影响」，附对应稿件或局部；把猜测与可见问题分开 | |
| 修改轻重 | 标明必须改、建议或个人偏好；必须改要说明与哪项已定要求冲突，偏好由创作者取舍 | |
| 预期改法 | 准备调整哪处轮廓、体块、连接或色块？先试最小改动；什么画面变化才算改善？ | |
| 保留原稿 | 另存可编辑原稿和修改前预览；候选放新图层，不覆盖原图，不删除或合并原层 | |
| 画改与完成 | 在 Krita 新建画改层，圈出问题并涂画调整；先看简化效果，再用手绘或剪贴补全连接、结构与边缘，留下修改后图 | |
| 若用 AI 局部重绘 | 先确认当前工具已有局部编辑实测支持；保留输入、区域与失败结果，新结果放独立层，检查边缘及区域外变化。画改示意不保证生成受控；不可用就手绘 | |

## 三、修改是否真正改善了角色？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 前后对比 | 放入真实修改前后图，在相同尺寸、背景下看全图与局部；原问题哪里改善，哪里仍未解决？ | |
| 整体复核 | 再看缩略图、关键动作和必须保留的特征；细节增加是否反而削弱身份、功能、气质或焦点？ | |
| 取舍 | 创作者按前后证据决定接受、拒绝或继续试改，并写原因；AI 意见只是建议，未获确认不写已接受 | |
| 回退 | 未改善或改坏时，关闭候选与画改层，确认原稿恢复；写恢复后的稿件与下一次改法。需更换核心方向则回[阶段五](<../执行手册/05_方向锁定.md>)重选 | |
| 完成与交接 | 必须改的问题解决、实际改图经创作者确认后，将完整角色稿与关键说明交[阶段七](<../执行手册/07_定稿交付.md>)；未决问题写明去向。空表或文字推演不算画改验证 | |

# 阶段七｜定稿交付

填写目标：整理一份能让自己或接手者 **看懂角色、找到文件、继续制作** 的设计资料。

人和 AI 使用同一张表。按「确认用途 → 准备必要图与说明 → 检查交接」填写；图件按实际需要选择，不需要的写明原因，不默认制作完整三视图或 3D 资料包。

## 一、这些资料接下来用来做什么？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 后续用途 | 谁接着做什么？是继续画插画、绘制其他姿态，还是制作模型等？接手时必须能回答哪些问题？ | |
| 已定稿件 | 引用[阶段六](<../执行手册/06_评审收敛.md>)确认的角色稿与关键说明；还有哪些未解决之处会妨碍后续使用？ | |
| 必须保留 | 哪些比例、剪裁、配色、道具或不对称特征决定角色身份？哪些允许随姿态与表现方式变化？ | |
| 文件要求 | 根据用途约定画幅、分辨率、格式、透明背景等；交付位置在哪里，需要哪些可编辑文件？ | |

## 二、哪些图与说明能把设计讲清楚？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色主图 | 展示整体比例、主配色、关键剪裁与身份特征；填写采用的图件，以及尚需整理的地方 | |
| 必要辅助视图 | 主图看不清什么，下一步又必须知道什么？据此选正、侧、背或局部视图，写清每张要解决的问题与图件 | |
| 细节拆解 | 只放大需要解释的部件，用箭头和短注说明固定、穿脱、持握、活动与材料关系；记录对应图件 | |
| 表情与姿态 | 后续制作是否需要知道性格、动作幅度或衣物装备如何随动作变化？需要才补图，并写其用途 | |
| 设计说明 | 图上难以直接表达的功能、材质、保持要点或允许变化是什么？把说明放到对应部位，避免只写抽象气质词 | |

## 三、交出去以后能否继续制作？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 跨视图核对 | 有多视图时，在 Krita 用头顶、肩、腰、膝等水平参考线核对比例与构件位置；区分透视变化与真正画错，检查左右与不对称关系 | |
| 图文一致 | 对照主图检查辅助图、拆解与说明的形状、连接、配色和材料；矛盾要先修，不能靠排版掩盖 | |
| 可编辑源文件 | 另存并重新打开实际 `.kra` 文件，检查角色、道具、说明等图层能继续编辑；保留原稿，不为整理而擅自合并或删除图层 | |
| 导出与查找 | 导出所需预览，核对尺寸、裁切、透明背景和文字可读性；写出主图、辅助图、说明与源文件的实际位置 | |
| 接手检查 | 实际打开资料后，能否找到已定稿、看懂关键结构、知道哪些特征要保持？请实际接手者确认；自用则自行检查，未检查写待确认 | |
| 完成或补回 | 所需图件一致、源文件可编辑且交接清楚才完成；缺图留本阶段补，设计本身仍有矛盾回[阶段六](<../执行手册/06_评审收敛.md>)。继续画插画时交[阶段八](<../执行手册/08_最终插画.md>) | |

# 阶段八｜最终插画

填写目标：让已确定的角色在一个画面事件中，鲜明地表达核心幻想。

人和 AI 使用同一张表。按「画面事件 → 构图与光色 → 完成检查」填写，随实际绘画补上稿件位置和判断；填表不能代替成图、源文件或真实评阅。

## 一、画面事件：这一刻为什么值得画？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 设计依据 | 对照[角色意图卡](<../执行手册/01_立项定位.md>)和已确认设计稿，填稿件位置及本图必须保持的角色特征 | |
| 核心幻想 | 本图最想让观众感受到什么？从意图卡选择本次重点，不重写角色设定 | |
| 关键瞬间 | 角色正在做什么、为何行动、是什么情绪？这一瞬间怎样体现上述吸引力？ | |
| 人物与环境 | 角色在与谁或什么发生关系？动作、视线、道具和环境中，哪些线索能让观众读懂事件？ | |
| 交付用途 | 沿用项目约定的观看场景、画幅、尺寸与格式；有多种裁切时，注明必须保留的表达 | |

## 二、画面选择：怎样让观众看见重点？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 构图比较 | 画有实质差异的小稿，数量按问题决定；比较观众位置、远近、俯仰与人物关系，填各稿位置、表达效果和损失 | |
| 选定构图 | 选哪稿、为什么？动作线怎样引导视线？按交付画幅试裁切，检查头、手、关键道具和轮廓是否仍清楚 | |
| 空间与动作 | 用简化体块检查透视、支撑、接触和遮挡；写出需要先修的关系，再进入细化 | |
| 明暗安排 | 画少量灰阶小稿；缩小看先读到什么、再读到什么，主体是否与环境分开，哪里抢走焦点 | |
| 光色决定 | 做小尺寸色稿，比较必要的光源与冷暖变化；选定光向、画面情绪和焦点，核对光照下的角色主色 | |
| 精修重点 | 按观看顺序分配结构、边缘和材质细节；每轮只解决明确问题，缩回全图检查是否改善事件表达 | |
| 修改保留 | 画改、AI 细化或放大均用新层或副本，保留修改前稿；检查整图的脸、服装、道具与边界外变化，设计漂移则拒收，结构错误先画改 | |

## 三、完成检查：画对了，也表达出来了吗？

| 检查项 | 填写提示 | 检查结果 / 稿件位置 |
|---|---|---|
| 角色身份 | 对照已确认设计，逐项核查比例、脸、服装与道具；区分透视和光照造成的合理变化与擅自改设定 | |
| 观众读图 | 请真实读者先描述「谁在做什么、感受到什么」，记录原话，再对照核心幻想判断；尚无反馈写待评阅，不用 AI 评分代替 | |
| 画面完成度 | 在实际观看尺寸检查事件、焦点与裁切；近看结构、穿插、边缘和接缝。记录还影响表达的具体问题 | |
| 停止精修 | 核心表达、身份、结构和规格都成立后，剩余修改是否有明确收益？确定停止，或只补一项可检查的改善；未过关键检查不标成品 | |
| 真实交付 | 填最终图、可编辑源文件及构图／灰阶／色稿位置；实际打开核对尺寸、色彩、裁切与图层可编辑性。未打开写未验证，缺作品写未完成 | |
| 必要回退 | 读图不清回构图或光色；局部结构错先修画面；设计本身不成立回评审，需改变已定角色特征回方向锁定。保留旧稿，写清重查什么 | |
