# 八阶段人机协作设计执行手册（实验性候选）

目标是让每一步真的改变画面或设计决定，而不是多填一张表。人、AI、协作都可执行各阶段；项目指定的人决定意图、方向与验收。执行者不等于决策者。本手册独立于[八阶段 v0.3 审核初稿](../角色设计八阶段工作规范_审核初稿.md)，不改变其审核状态；[阶段一原表](../阶段一_角色意图卡_模板.md)保持原样。

## 八阶段总览：输入、动作、分工、产物与门槛

| 阶段与手册 | 输入 | 核心动作 / 创作抓手 | 人与AI分工 | 产物 | 通过 / 回退 |
|---|---|---|---|---|---|
| [① 立项定位](01_立项定位.md) | 模糊想法、用途、已有条件 | 拆主题/幻想/功能；用“拿走能力”反事实找到人物吸引力 | 协作追问，人定优先级 | 原意图卡、I约束、Q问题 | 不看图能复述是谁/吸引力/差异；互斥要求回用途 |
| [② 前期调研](02_前期调研.md) | 意图版本与Q | 拆现实原理，跨对象借结构；遮掉无用参考 | AI搜线索/提转化，执行者查原文，人决定采用 | 注释板、S来源与三条转化链 | 能从选择追到依据；无依据回查源或明确为虚构 |
| [③ 创意提案](03_创意提案.md) | I/Q/S | 翻一个前提，提出三种功能或隐喻解法，主动写反证 | 协作发散，人确认入围范围 | P提案、粗图、H假设 | 去掉色彩仍不同；只是换皮则重提 |
| [④ 方向探索](04_方向探索.md) | P/H与不变量 | 剪影→结构动作→明暗配色→比较；一次测试一个关键变量 | 人/AI做稿，人选可解释的候选 | 探索板、实验观察、短名单 | 有可比较的视觉证据；没有有效解法回3，现实依据缺失回2 |
| [⑤ 方向锁定](05_方向锁定.md) | 真实探索证据、优先级 | 明确选择的损失，压成2–3条支柱 | AI做反方/整理，人选唯一主方向 | 选定稿、F支柱、废案与重开条件 | 有图有决定；缺证据只能暂选，回4 |
| [⑥ 评审收敛](06_评审收敛.md) | 主稿、F、待解决问题 | 结构/细化/材质三轮；局部画改和失败对照 | AI提问题/建议，人判修改是否改善 | 修订稿、R反馈、前后对比 | 关键问题有可见改善且不漂移；支柱冲突回5 |
| [⑦ 定稿与交付](07_定稿交付.md) | 收敛稿与下游目的 | 按接手者的问题补视图和构件拆解，再重开源文件 | 协作整理，人核一致性/可编辑性 | 主图、必要辅助视图、Callout、设计包 | 接手者能继续做；结构缺口回6，不靠排版掩盖 |
| [⑧ 最终插画](08_最终插画.md) | 设计包或手工锁定设计、幻想 | 写事件，换镜头、灰阶、光色，再精修；准确性与感染力分验 | 人/AI制作，人选叙事瞬间与终稿 | 构图/灰阶/色稿、最终插画、源文件 | 幻想可感知、特征一致、交付规格满足；画面问题在8，设计问题回对应阶段 |

步骤表是教程，不是要求逐行填写的工作日志。首次看每阶段「协作步骤表」与「最小填写卡」就能开做；遇到困难再查详细教程。每个阶段保留九个操作章节，未使用工具可直接走手绘/文本路径。

## 轻量执行：一次只决定一个问题

| 使用情况 | 最少留下什么 | 何时扩展 |
|---|---|---|
| 一个人短练习 | 输入版本、一句问题、产物、决定及下一步 | 多轮结果混淆才加稳定ID与对照板；本案例已有ID可直接沿用 |
| 完整角色创作 | 意图卡；每阶段一张最小卡；图像与关键来源 | 风险、失败或分歧出现时展开对应模板，不把所有模板当表单税 |
| 多人接手 / 长期项目 | 上述材料加接手者、已定/可改、版本变更 | 接手者误读、多人改同一文件时补复述和文件索引 |
| 教学演练 | 标明教学假设、示意路径与尚欠的真实证据 | 真实创作时替换为作品与实测，不能仅改状态字样 |

阶段1直接用原表，未知可填待定，不强求编造背景。阶段2三条链、阶段3三案、阶段5两三条支柱是本教程的起步练习；后续迭代只填变化项。数量不是质量评分，项目硬约束与关键证据不可省略。

## 最小交接协议：一张卡，不是数据库

| 字段 | 写法 |
|---|---|
| 项目 / 阶段 / 版本 | 雾港引路人 / 04 / v02；以下命名仅为人工约定 |
| 输入 | 文件及版本、必要ID；指向旧记录，不重抄全部 |
| 本轮问题 | 只写要决定的一件事，例如肩灯是否阻挡伸手 |
| 执行 / 决策 | 人、AI或协作负责制作；指定的人确认方向和通过 |
| 产物 / 证据 | 文件或板面区域；分别写来源查阅、静态推导、真实作品测试、真人评阅 |
| 结论 / 交接 | 已定、未定、阻塞、下一动作及接手者；没做写待验证 |

记录可附在图边或现有文件，不必另建文档。I=意图约束，Q=问题，S=来源，P=提案，H=假设，F=设计支柱；后续可用X04实验、R06评审、PK07包、C08镜头。含义改变须新增ID或写版本变更，不能偷偷复用。建议本地文件 `01_意图_v01.md` 到 `08_插画_v01.kra`；这是新项目建议路径，教程没有交付这些真实文件。真实 `.kra`、原参考和生成结果留在个人项目，不随公开文档上传。

## 允许回退，也允许并行

不要求每次从1走到8。阶段8可先试画面事件检验角色幻想；阶段7可提前拟接手问题；但正式下游交付必须等它依赖的设计决定与证据成立。教学推演可用暂选稿，真实制作不可把暂选写成已锁定。

| 发现的问题 | 回到哪里 | 保留与暂停 |
|---|---|---|
| 画得漂亮但角色不再吸引人 / 用途改变 | 1，重新决定幻想与优先级 | 保留图像备选，暂停受新用途影响的终稿 |
| 参考不可靠 / 文化或功能解释错误 | 2，重查对应S | 保留无关结构，暂停依赖该来源的设计结论 |
| 三案本质相同 / 没有可用解法 | 3 | 保留I/S，换关键前提，不重复抽卡 |
| 黑剪影、连接或动作失败 | 4；若无解回3 | 保留有证据的变量，只重做失败实验 |
| 修改破坏F或人改变审美选择 | 5，显式重开 | 保存旧决定；列受影响F及下游文件，不默认全部解锁 |
| 局部工艺/材质未做好 | 6 | 新层画改，保留原稿与失败结果 |
| 多视图矛盾 / 文件打不开 | 7；结构本身有错回6 | 修对应页/文件并重验，不能只导出新封面 |
| 构图情绪、裁切、焦点不成立 | 8 | 先重做低成本小稿；不为救构图偷偷改角色支柱 |

每次回退只记「原因→受影响ID/文件→保留什么→重验条件」。重开不是失败惩罚，而是避免在错误假设上精修。

## 贯穿案例与证据边界

岑灯是虚构的雾港引路工：普通人通过灯与空手引导他人。已有[意图卡](案例/雾港引路人_意图卡.md)、[调研](案例/雾港引路人_调研.md)、[三案](案例/雾港引路人_提案.md)、[方向决策](案例/雾港引路人_方向决策.md)；各新阶段继续这一案例，不各造一个主角。

本批文档和原创示意可检查可读性、链接与内部一致性；三条现实来源曾核对正文。没有真实模型试跑、Krita操作录像、新手测试、另一位设计者评阅、正式插画或可编辑 `.kra`。因此文档齐备不等于Issues #1–8或项目级艺术验收通过。验收勾选留给实际执行者；不能用文档审查替代真人评阅。

外部图像只链接，不视为已获转载许可；自绘SVG为教学示意，沿用仓库design许可。文件以静态可读为目标，不承诺Krita导入后文字可编辑。工具使用建议须在目标环境核验，程序能力以[仓库说明](../../README.md)及当前实现为准，手册不新增功能。
