# 02 前期调研：参考搜集、结构分析与设计转化

## 阶段目标

交付一张能解释设计依据的注释参考板，至少三条「来源 → 功能/结构 → 原创转化」链条。先做薄版，不追求堆满图片。

## 输入材料

[阶段一](01_立项定位.md)的意图卡、I 约束及 Q 问题；本案例沿用[岑灯](案例/雾港引路人_意图卡.md)。没有问题先回阶段一，不漫无目的搜美图。

## 协作步骤表

| 步骤 | 输入与问题 | 具体动作 | 执行与决策 | 产物 | 通过或回退 |
|---|---|---|---|---|---|
| 1 按问题找 | 意图版本、Q/I | 每个Q写一个“若没有答案就无法画”的结构问题，再找原机构说明 | AI列检索候选；执行者查正文 | 问题—来源索引 | 来源回答问题；否则改搜索词，不堆图 |
| 2 拆事实 | 原文、图像权利 | 分别记事实、结构观察、设计联想；来源未知不填假作者 | 人/AI提取；人核验采用依据 | S来源记录 | 事实可定位、使用边界清楚；不清楚只保留线索 |
| 3 迁移结构 | 2–3主参考 | 做“远亲借结构”：不借整套灯塔外形，只借聚光与分段组织，移到可携装备；画一项不适配反例 | 协作推导；人决定可试转化 | 参考板的原理→结构→角色三层 | 改变功能组织而非换色；负重未证标风险 |
| 4 删与交 | 注释板及链条 | 逐张遮住参考：不影响任何设计问题的移补充区；留下三条不同问题链 | 人/AI整理；人确认进入提案 | 薄参考板、未解Q | 三条链可追溯；缺真实依据回步骤1 |

执行分工可以互换；方向、优先级与阶段通过由指定的人确认。以下长教程是查阅说明，记录只填下一张最小卡，不必逐步抄写。

## 人类操作

1. 建五类目录或板面标签：文化与职业（谁在何种条件工作）、装备功能（如何携带/使用）、服装材料（连接与活动）、造型表达（大形/明暗）、同类对比（已有套路与差异）。类别可以暂空，写原因，不能编造文化事实。
2. 为每个 Q 写关键词：对象 + 结构/行为 + 来源机构，例如「lighthouse lens structure site:nps.gov」「cork lifejacket canvas construction site:rnli.org」「buoys shape colour site:trinityhouse.co.uk」。中文可试「灯塔 透镜 结构 官方」「救生衣 历史 材料」。先查原机构说明，再沿引用追溯；搜索摘要不能替代正文。
3. 筛选每项来源：是否回答具体问题？是否找得到作者/机构、日期、上下文？是否能说清现实结构而非只觉得好看？图片是否可用？不明出处的拼图只作待查线索；生成图不是现实事实证据。
4. 主参考只留 2–3 张，分别承担不同问题。本例是 S1 聚光、S2 分节服装、S3 航标编码。若不许可复制照片，自己画结构分析图并标明是推导示意，旁边链接来源。主参考是决策依据，不必是照片。补充参考按问题存放，不挤占主板。
5. 每条记录分四栏：可核查事实及来源、看到的结构、为何适合/原创转化、版权与未知。把「事实」和「我打算这么设计」明确分开。[调研案例](案例/雾港引路人_调研.md)示范了三条完整链。
6. 作板：每栏上部画现实结构的简化示意，中部用箭头标受力/分节/方向，下部画拟采用的原创结构；写 Q/I/S 编号和一句失败风险。不要沿着照片描完整角色、整套服装或标志。
7. 同类对比先做有限的结构比较：手持灯旅人、重甲守卫、固定灯塔是本例自拟的功能原型，不声称调查了真实市场角色。加入现有 IP 时另记作品、作者和仅分析的维度，不照搬轮廓与纹样。没有证据的「从未有人做过」不能写成独创性结论。

## AI 可代劳事项

可用：「按 Q1–Q3 给搜索词；只把我给出的已查阅来源写成事实，逐项区分事实/推断/建议/版权未知；提出三种结构转化，不复刻照片造型。来源缺失时标待核查。」AI 可分类与画分析框，不能补假链接、假作者、假授权。人核对网页原文和图片权利。

## Krita/ComfyUI 操作

以下是待实机验证的手工操作建议，未在 Krita 6 实跑；不需要插件 API 或模型。

1. 新建参考板文档（建议 1800×1100 px，尺寸可改），另存到自己的本地项目，不覆盖作品。
2. 新建 `00_标题出处`、`10_S1聚光`、`20_S2分节`、`30_S3路标`、`90_待验证` 图层组。每组分 `参考或自绘示意`、`结构分解`、`箭头`、`文字` 图层。命名是人工约定，不宣称程序自动创建。
3. 可将本教程 SVG 在图像查看器中阅读或导出 PNG，再作为新图层导入；导入方式与 SVG 文本可编辑性需在实际 Krita 版本确认。不要把扁平 PNG 当成可编辑的文字图层。
4. 在新透明图层画连接、活动空间与箭头；文字工具不熟时，用独立 Markdown 注释配 S 编号，仍可追溯。缩放读一遍，保证箭头指到结构而非装饰。
5. `.kra` 留本地；导出供评阅的 PNG，保留原参考层，不合并/删除原图。模板的空位需填来源和状态。

ComfyUI 此阶段非必需；如用它做联想，归入「设计推断」，不能替代现实参考。不得把生成图误标为历史照片或安全装备结构。

## 最小填写卡与可选扩展

复制参考记录模板的薄版，只保留影响当前决策的三条链。

| 填什么 | 本轮记录 |
|---|---|
| 项目 / 阶段 / 版本 | 项目名；02；v__ |
| 输入 | 上游文件与版本，可引用不重抄 |
| 唯一问题 | 本轮决定什么，观察到什么会改变决定 |
| 执行与决策 | 人/AI/协作；指定决策者，未确认写待确认 |
| 本阶段最小内容 | Q→S事实位置→结构转化→风险/使用限制。三条链可放同页。 |
| 产物与状态 | 文件/板区；来源查阅/静态推导/真实作品测试/真人评阅分别记录 |
| 结论与交接 | 已定、未定、下一步、接手者；未测试不写通过 |

按需扩展：涉及文化符号时补文化上下文；转载图片时补作者/授权；来源冲突才做对照；补充参考不逐张写长卡。

## 输出文件

本地 `02_参考板_v01.kra`（若用 Krita）、可读 SVG/PNG、`02_来源与推导_v01.md`。可复用[参考板模板](模板/注释参考板.svg)、[记录模板](模板/参考记录.md)。完成示例：[参考板](案例/雾港引路人_参考板.svg)、[离线文字链条](案例/雾港引路人_调研.md)。示例不含第三方照片；断网仍能阅读推导，但不能离线复核外部原文。

## 人工验收

- [ ] 有 2–3 项主参考，五类有归属或明确待查说明。
- [ ] 至少三条链能从 Q 追到 S、现实结构和原创选择；不靠单张美图证明全部设计。
- [ ] 事实、设计联想、版权限制分别标明；每个外部来源能打开或已标失效。
- [ ] 任指核心元素，能回答现实来源、功能依据、预期转化；推断不冒充实测。
- [ ] 断网可打开板和记录；外部原文复核仍需联网。真人读板与 Krita 验证状态单独记录。

## 失败回退

来源失效：保留 S 编号并标「待复核」，暂停相关事实结论；找机构替代或亲自拍摄获准物品，不用无出处图片补洞。只有风格词：回 Q 问「如何工作」；来源互相冲突：并列证据与日期，不强行合并。板太满：每个 Q 留最能解释的一条，其余移到补充区。
