# 阶段8｜插画制作与交付

> 现行手册；稳定 ID：`illustration_production`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

在阶段七确认的同一 Krita 插画文档中制作，不重新海选。线稿/参考、确认稿、制作组、AI 候选与诊断分开。每次 AI 修改明确文档、源版本、区域、目的、保留项和输出位置；先回新候选，再比较、接受或拒绝。没有有效蒙版、身份或映射只保留独立候选，不自动写回。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 8A 制作准备 |保存确认稿；明确工作区、分辨率、当前基底、参考与保持要点；产物：可恢复的 `.kra` 版本和清楚图层组；核查：不会把另一候选当基底| |
| 8B 整体成形 |依据构图、线稿与颜色关系建立整体底画；允许 AI 辅助；产物：与确认稿一致的整体候选，保留线稿/参考；核查：主次、动作、比例没有被重新设计| |
| 8C 关键结构与焦点完成 |优先脸、手、肢体、服装连接、道具等确实影响表达的部分；产物：分区修改候选及接受/拒绝记录；核查：重要问题得到实际修正| |
| 8D 材质与细节 |根据材质和重要性补必要信息，不平均铺满细节；产物：可继续调整的局部与材质层/版本；核查：细节服务身份、焦点与叙事| |
| 8E 全图统一 |统筹光向、色温、边缘、对比和纹理密度，清除局部拼贴感；产物：整体协调的完成稿；核查：缩小、正常观看、局部查看均可理解| |
| 8F 尺寸与收尾 |按目标像素尺寸输出；必要时受控放大并复检新增问题；产物：指定尺寸的图与放大前版本；核查：不用放大代替修结构，不强制超分| |
| 8G 验收与导出 |检查表达、身份、源文件与实际导出物；产物：最终 PNG、可编辑 KRA、角色设定、交付清单；核查：重开源文件并核对导出无参考/诊断污染| |

**完成与交接：** 最终图与可编辑 KRA、角色设定、交付清单一致；实际打开核对像素尺寸、色彩、裁切、透明度、层与导出范围，无参考、红圈、诊断污染。核心表达与规格成立、主要问题解决后由作者决定停止，不以模型自评分或装饰量判断完成；无作品就记未完成。
