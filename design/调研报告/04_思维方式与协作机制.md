# 报告四：思维方式与协作机制专题 —— 角色设计链路的"软件"

> 行业案例与方法参考；本项目执行以[正式规范](<../Krita中枢创作流程_正式执行规范.md>)为准。本文的阶段名与数量不构成本项目要求。
> 本报告把前三份报告中的案例提炼为可迁移的思维方式与协作机制。每条原则均给出实例来源。

## 一、设计思维的核心原则（What to think）

### 1. Fantasy First —— 幻想先于外观
- **原则**：动手前先回答"玩家/观众想成为什么、想感受什么"，外观只是幻想的载体。
- 实例：拳头按"玩法幻想缺口"立项英雄（"需要一个开团型上单"）；皮克斯《头脑特工队》先把情绪定义成抽象能量形态；Thompson"从角色出发而非从风格出发"；天美用户认同三层次（"他是我想成为的样子"）。
- **操作化**：写一句"幻想宣言"（烬 = "舞台上的完美主义杀人艺术家"），后续所有评审只问一个问题：这张稿是否服务这句话。

### 2. Theme / Fantasy / Function 三层论
- Theme（主题定位：角色在世界观的坐标）→ Fantasy（玩家的自我投射）→ Function（战斗/叙事/交互需求）。三层缺一即失衡：只有 fantasy 会空洞，只有 function 会平庸（"及格的角色"——鸣潮仇远原话）。

### 3. 形随功能（Form Follows Function）
- 春丽粗腿=设定推导（池野大悟）；Thunderjaw 的概念审美反推武器设计（Guerrilla）；藤岛"设计要保证旅行时不便"；FZD 启动公式=文化+时代+要解决的功能。
- **反例文化**：二次元 aesthetic-first（星铁"每轮迭代都变好看"）是另一种价值排序——两种取向没有对错，但团队必须显式选择并保持一致（王者演讲的东西方差异分析）。

### 4. 90/10 参考法则与考据
- FZD："真实参考驱动 90% 的基础设计，最后加 10% 差异"；Gurney《Imaginative Realism》的完整证据链（考据→maquette 实光拍摄→写生→what-if 嫁接）；云堇请京剧演员考证；Doc Ock 参考真实女性科学家。可信度来自现实逻辑，不来自灵感。

### 5. 约束是生产力
- 池野"在限定范围内思考，尽量不掺个人爱好"；藤岛"避免拉链"；鸣潮"盲人如何战斗？"的追问；OW"翻新不可动色板/剪影/运动感"；《Skillful Huntsman》的 what-if 改写。先给问题再加限制，方案自然涌现。

### 6. 先文字后图像
- Bobby Chiu：动笔前用词语定义角色（施瓦辛格="老、壮、方下巴、牙缝、眯眼"）；皮克斯先写情绪关键词。词汇量=与艺术总监沟通的能力——说得出才画得出。

### 7. 可读性前置（Readability by Design）
- TF2 读取层级（队伍→职业→武器）；九兵种剪影显式互不相同；暗黑双镜头检验（远读剪影/近读细节）；王者"大剪影造型上下功夫"。可读性是概念阶段写入的约束，不是后期补救。

### 8. 形状语言与色彩心理
- 圆=友善、方=稳定、三角=危险（迪士尼七步之一）；主角群内部形状互补；主色定性格+限色板。

## 二、发散与收敛的方法（How to explore）

### 发散工具箱
1. **Thumbnails（8-20 个小稿）**：只求量与差异性——thumbnail 不是画得小，是**决策成本低**（失败快、比较易）。
2. **Silhouette pass**：纯黑形块海选，验证远距可读性（《Skillful Huntsman》教学范式）。
3. **Crazy 8s / Evil 8s**：8 格 8 分钟强制产出；变体专画坏点子。
4. **Bad ideas first**（FZD）：先列最烂方案解除心理门槛再翻转。
5. **激进范围**（拳头 Kindlejack）："在速写本上涂一个 pretty radical range of directions"——探索期故意超出安全区。
6. **迭代循环（iterative design loop）**：宽→窄→宽的漏斗，每轮以外部反馈校准；Kekai"总是重做已有内容逼近最优解"。

### 收敛机制
1. **方向锁定的仪式**：拳头 final pitch（计划+使命宣言）；暴雪标杆角色（托比昂）；星铁多轮迭代收敛。锁定之后改动成本陡增——"越晚改越痛苦"。
2. **第一意图最贵**（Sparth）：基础草图确立后不大改初始构图；最好的图往往从头到尾构图未变。
3. **逃离抽象**（Sparth）：元素就位后必须进入细节，别玩无意义的形状颜色。

### 数量级参考
- 拳头：9 个月英雄周期中 5 个月在预生产；Ornn 近 4 年；VGU 玩家投票排产。
- 任天堂：林克近 100 版；暴雪：48 概念海选→21 上线；Guerrilla：Thunderjaw 1.5 年。
- 结论：**成熟管线的迭代次数以十/百计，不以求一次到位**。

## 三、协作机制（How to work together）

### 组织形态
1. **跨职能小队**：拳头"玩法+叙事+概念"三人组起步，后期扩到约 19 个职能；米哈游跨部门共创；Diablo IV 角色方向细分到 Associate AD。
2. **创意权下放**：Guerrilla 45 人 pitch 大会；暴雪全员海选；拳头历史上的 "Hot or Not" 内部竞赛。共同规律：**会画的人天然占优**（可视化=说服力）。
3. **双向驱动**（Diablo IV 官方口径）："有时概念先行（Skeleton Lord），有时设计文档先行（Blood Bishop）"——不规定谁服务谁。
4. **反馈电路而非接力赛**（Sony）+ **评审前置化、多元化**（星铁立项采访全员、绝区零跨部门）。

### 评审文化
1. **讨论 > 评分表**（Guerrilla："我要感受大家的热情"）；"Yes, and…" 文化（暴雪暗黑）。
2. **Paintover**：总监直接在画布上涂改示范意图，比文字反馈快一个量级。
3. **建设性反馈三则**：先问意图再给方案（"这里想表达什么？"）；描述影响而非指责（"这个肩甲让剪影变糊"）；区分"必须改/建议/个人偏好"。
4. **单一反馈出口**（外包铁律）：避免多个评审给矛盾意见；每阶段明确"此刻批准的是什么"。
5. **把 notes 当数据**（Sparth）：好建议记入扁平的"must not forget"清单反复重读。

### 冲张力的正面价值
- 安藤雅司：监督要"难画的演技"，作监判断可行性——张力本身是质量机制。
- Ornn 獠牙 vs 山羊角之争→"ram 撞头=铁匠锤击"同时满足美术与玩法——冲突常以找到"互证隐喻"收场。

### 交付物契约（本任务终点：角色插画/原画）
| 交付物 | 用途 |
|---|---|
| Character brief | 启动的唯一事实源（性格+世界观+约束+参考） |
| Thumbnails / silhouette sheet | 评审淘汰用 |
| Final concept（定稿概念） | 方向锁定的正式产出 |
| Turnaround（三视图） | 下游对齐比例结构 |
| Callout sheet（拆解图） | 武器/材质/纹样放大标注 |
| Expression sheet（表情表） | 角色性格延展（日本体系标配） |
| Key visual / Splash（角色插画） | 最终商用形象——"幻想制造器"（拳头 GDC 理念） |
