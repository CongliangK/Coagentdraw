# 阶段6｜三视图设定与核对

> 现行手册；稳定 ID：`turnaround`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

在 Krita 独立三视图文档中放已确认主稿，建立正、侧、背区位与头顶、肩、腰、膝、脚底共同水平线；稳定站姿、弱透视，先展开侧面再补背面，必要时回修正面。三图各有线稿与基础色可独立修改。侧面标角色自身左/右，画面左不等于角色左；不对称部件补另一侧局部或说明。

02 搜到的参考角色三视图只是前端材料；本阶段交付的是当前原创角色的正侧背，不能以参考三视图已找到、导入或拼好作为本阶段完成。

模型提出的背部是待确认设计，不是从正面准确还原的事实。逐件核对数量、边界、固定、穿脱、持握、活动、遮挡与配色；排版或像素对齐不能替代结构判断。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色版本 | 关联阶段五确认的版本，不混用不同候选 | |
| 正面 | 清晰线稿与基础配色；作为核对基准之一 | |
| 侧面 | 写明角色左/右侧；检查厚度、遮挡和活动空间 | |
| 背面 | 衣物延续、固定方式、背负装备及不对称关系 | |
| 共同比例 | 头顶、肩、腰、膝、脚底等在相同基准下核对 | |
| 同一构件 | 边界、数量、连接和配色能否从一个视图延续到另一个？ | |
| 局部说明 | 只补影响理解的连接、材质或结构 | |
| 修订与确认 | 哪些问题已修，哪些属于允许变化，作者确认什么？ | |

**完成与交接：** 作者并排确认同一设计的结构、比例、左右和基础色一致；保存并重开检查三图关键层可编辑、绑定可找。三次独立文生图、正面镜像、六图拼版均不能代替核对，不要求宣传级精绘。
