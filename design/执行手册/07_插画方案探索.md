# 阶段7｜插画方案探索

> 现行手册；稳定 ID：`illustration_planning`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

角色与三视图成立后，在本幅 Krita 插画文档中确定怎样观看和感受这个角色；尚无插画文档时再按本幅用途建立。作者持续统筹同一张主稿的表达、取舍与确认，助手围绕当前稿协助绘制和比较。图像承担主要记录，图旁留表达目标、选择理由与当前问题的短句，不重复填写角色长篇设定，也不以作者先会精绘为条件。

本阶段以三轮内部工作推进：**表达与构图动作比较 → 结构与空间 → 结构与光色确认稿**。相邻工作可以合并、往返，不新增宏观阶段、独立表单或逐轮审批。早期插画灵感可以继续发展，但不能替代本阶段的可见依据与作者确认。

沿用现有组层：角色资料和短意图放 `00_角色参考与画面意图`，小稿与结构/光色分支放 `10_构图候选`，选中的结构与光色依据放 `20_确认稿`；新 AI 结果先放 `40_AI修改候选`，圈示、灰阶等观察副本放 `90_诊断与比较`。保留原稿与未选稿，候选不自动覆盖主稿；下一阶段在同一文档的 `30_制作` 中继续。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色依据 | 引用已确认三视图的文档、组/层与版本，指出本镜头必须可读的身份特征。透视和遮挡可改变可见形状，不要求把所有装备同时展示出来，也不借插画静默换装。 | |
| 本幅表达任务 | 用一两句话说明最希望观众看到或感受到什么，通过什么动作、状态或关系呈现。事件只是入口之一；安静肖像、情绪、人物关系或形象气质同样成立，不必编造复杂情节。 | |
| 用途与画幅 | 沿用作者已定的用途、像素尺寸与比例，在此画幅内比较构图裁切；未指定不冒充已确认。小稿、缩小、灰阶和轮廓检查只用显示缩放或观察副本，不擅自改变源 KRA、既定画布或交付尺寸。 | |
| 第一轮·画构图与动作 | 同时安排人物位置与大小、动作或状态轮廓、镜头远近俯仰、主要环境块面、前后关系及大致亮暗。镜头与动作一起试，不先把姿态定死再单选镜头。粗线、色块、拼贴、姿势参考或 AI 小稿均可，不要求漂亮线稿。 | |
| 第一轮·比较与保留 | 同尺度并置或切换，缩小看第一眼落在哪里、状态/关系是否读得出、感受是否符合目标；细致 AI 图必要时再看灰阶或轮廓，避免纹理盖过判断。没有方向可先试三张差异明显的小稿，三张不是配额、上限或完成标准；有明确方向可直接发展当前稿。保留未选稿，只短记选哪张、为什么；新一轮要回答新问题，不只换种子。 | |
| 第二轮·补结构与空间 | 在选中稿上画清躯干与骨盆转向、主要关节、重心支撑、透视缩短、手与道具及身体与环境的接触、服装大轮廓和重要遮挡。只补会导致后续大幅重画的关系，不追求每个部位的终稿精度；视线与主要动作应服务本幅表达。 | |
| 第二轮·补依据与复看 | 轮廓错位可用粗线、选区移动或变形修正；关节/接触不清就补当前角度参考或 AI 结构候选。复杂俯仰与空间可用已有 Blender 能力搭必要的替身、地面、体块和相机/主光，辅助图回到 Krita 比较，不前置完整建模或新管线。保留结构依据；支撑、接触、遮挡仍说不清就继续解决，不用上色和纹理掩盖。 | |
| 第三轮·画明暗与光色 | 在选定构图上用大色块确定第一焦点、主要亮暗分组、主光方向、冷暖及主体/背景区别，次要区域允许压低或留白。能在色稿中控制明度时，黑白与色稿可同轮完成。方向不明才做有差异的光色对照，尽量保持同一构图；光线遮没重要表情或接触时，同步修正并复看整图。 | |
| 第三轮·留下确认稿 | 图上应看见：画幅与裁切、人物大小和位置、主要动作与支撑接触、前后遮挡、第一焦点、主要明暗分组、主光和冷暖关系。可保留结构线与色稿两个可切换依据，不必把所有辅助线叠在最终可见层，也不强制终稿级干净线稿。缩小后应已能判断预期观感。 | |
| 表达检查与当前选择 | 对照本幅目标看人物状态、关系和观看顺序，不能只看角色是否精致。若有真实读者，先请其自由描述第一眼所见与感受，再对照意图；作者自检、AI 诊断和外部反馈分清，不虚构读者验证。作者选择当前方案，短记版本与真正关键的保持关系；确认的是本轮制作方向，不是冻结所有像素。 | |

**执行边界：** 上述选区、变形与绘制由作者在 Krita 界面操作，或由已具备相应界面能力且获授权的助手操作；当前 CLI 没有通用笔刷、变形、滤镜接口。AI 可协助绘制结构和光色候选，但不保证锁定镜头、姿态或角色；圈示也不等于模型已收到硬空间约束。实际能力不足时明确指出未解决的关系，补参考、结构依据或由作者决定简化，不能以文字说明冒充画完、以自动美术评分代替作者判断。

**完成与交接：** 结构与光色确认稿已让本幅表达和上述画面关系可见，主要结构问题没有留待精绘掩盖，作者确认当前版本及保持关系，即可交给 8A/8B 建立整幅底画。保留插画 KRA、选稿与确认依据，并引用已有角色设定；需要独立修改的结构与颜色应保留真实起作用的层或蒙版，不把被不透明 AI 位图盖住的旧层当作新画面的可编辑分层。确认稿仍可能在实际展示尺寸暴露局部问题，不代表已经完成最终插画或工具实测。

**按问题回退：** 表达读不出，回第一轮比较镜头、动作/状态与构图，或第三轮调整光色；主要动作、支撑、透视不成立，回第二轮补结构。AI 改脸、改装备先对照角色依据修当前插画；只有原设定自身矛盾才回五/六。后期出现更好的大方向，保留旧稿再返回本阶段比较，由作者决定是否转向。
