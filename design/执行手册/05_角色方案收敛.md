# 阶段5｜角色方案收敛

> 现行手册；稳定 ID：`character_resolution`。工具能力见[能力说明](<../工具能力与验证.md>)；共用规则见[手册导航](<README.md>)。

承接04的拼贴原型与探索：选择方向 → 提炼保持要点 → 重构原创线稿 → 上基础色 → 圈出问题、实际修改 → 同尺度前后与全图复看 → 作者决定。打开同一 Krita 角色设计稿，保留原型与粗稿，清线、基础色和修改候选分开；引用02同一尝试记录，不再抄一套素材表。必要时对照标杆的夸张程度、形状语言和细节密度，不用总分抵消结构与功能问题。

原型到线稿的[教学示例与操作分工](<04_角色视觉探索.md>)在04；已完成的结构线稿和色彩试验直接沿用，05负责继续收敛，不重复起步。

从原型带走的是大型和设计关系；重新解决轮廓、连接、厚度、遮挡、穿脱与缺失面，具体纹理细节也重新设计。保留的核心识别组合须属于当前角色，不能把临时来源碎片、描边、滤镜结果或单张扁平生成图直接当作完成的原创主稿。线稿基本成立后上色；原图颜色不自动锁定，来源原图和拼贴层可留在工作文件参考/探索中，交付预览不得混入临时碎片或诊断。

修改记录区分必须改、建议、个人偏好；写明意图、位置、影响与预期改善。替换错误线条须有能消除旧形的独立替换分支，透明叠层不能擦掉底下旧线。不安全时放独立候选文档，不能逼作者承担全部手绘。拒绝恢复原稿，回看关键动作与身份特征；核心方向不成立可回探索重选。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 主稿 | 引用所选原型、当前线稿/平涂组及版本；不把原型当终稿 | |
| 保留要点 | 哪些比例、轮廓、衣物、颜色分区和道具决定角色身份？ | |
| 阻碍问题 | 直接圈出图上位置，不只写“还不够高级” | |
| 实际修改 | 对应修改前后图层或版本；记录是否采用 | |
| 清晰线稿 | 领口、肩线、腰线、穿插、装备连接是否说得清？具体结构与细节是否已再造？ | |
| 基础配色 | 主色/辅助/强调色在具体区域如何分布？ | |
| 尚需侧背面解决 | 标出正面无法决定的结构，不由 AI 假装已知 | |
| 作者确认 | 确认当前角色主方案；不等于确认插画构图 | |

**完成与交接：** 原创清晰主视图线稿和平涂成立，关键问题真实修订或明确处理，需单独调整的线稿、基础色与关键部件有实际有效层/蒙版，足以展开三视图。保存重开核对编辑作用，实际查看交付预览；原型看着协调或找到参考三视图都不等于本阶段完成。确实无须修改可记本轮无修改，但端到端真实试用至少一次实际修订。作者确认角色主方案不等于确认插画；侧背发现问题可回修并注明影响。
