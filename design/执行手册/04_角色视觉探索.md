# 阶段4｜角色视觉探索

> 现行手册；稳定 ID：`character_exploration`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

围绕阶段三选中创意开 Krita 角色设计稿：身体、衣物和道具一起改变比例、重心、轮廓与负形；粗线稿说明领肩腰线、剪裁层叠与连接；代表动作检查穿戴活动；独立基础色层比较颜色分区、面积和主次。结构改变大形就回看剪影。

候选以相近尺度、背景、视角和完成度并排；案内比较可一次改一组变量。软布垂落、硬件支撑、穿脱开口与固定位置必须说清；可用黑灰白诊断读取层级，再在预期背景看配色与远近阅读。数量由问题决定，不设强制八张/六张。填黑复制不是造型探索，边缘检测不等于结构成立的线稿，不强制先厚涂。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 本轮要看清什么 | 明确比较轮廓、衣服结构、道具、动作或配色中的哪项 | |
| 剪影/大形 | 身体、衣物、道具如何一起改变比例和重心？ | |
| 粗线稿/穿戴 | 把分开放的参考组合到同一个角色上，讲清轮廓内部结构 | |
| 结构与动作 | 谁压住谁、怎样固定、怎样活动？必要时补局部 | |
| 平涂配色 | 同一或相近结构下比较颜色在哪里、占多少，不只列色卡 | |
| 对比观察 | 并排看相近完成度的图，指出具体有效之处和代价 | |
| 下一步 | 保留哪些候选；哪个问题交下一轮修订？ | |

**完成与交接：** 能指出真实探索图的差异和代价，有可供收敛的候选。未画或未测明确标注，不要求所有候选探索所有维度。
