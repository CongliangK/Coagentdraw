# 阶段1｜文本创作起点

> 现行手册；稳定 ID：`text_seeds`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

低成本记录许多不同的人物、矛盾、行动、情境或意象；灵感池长期开放，没有固定总量配额。纯文本可先记在本地 `notes/ideas.md`。一旦有图或准备参加比较，在 Krita 想象板放短摘要与素材，保持各起点可辨认；不要求先填完整人设。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 起点 | 先用一句话或一小段记录，不要求完整背景 | |
| 吸引力 | 是什么人物体验、矛盾、行动或形象让它值得继续？暂不清楚可留空 | |
| 已知条件 | 只写作者已经明确的边界，不替作者补设定 | |
| 可能分支 | 这个起点还可以怎样变化？与哪条旧想法相连？ | |
| 关联素材/画布 | 有图就记位置；没有图不判失败 | |
| 当前状态 | 继续发展、暂存、合并线索或不做本轮 | |

**完成与交接：** 有值得带去看素材的起点即可进入阶段二；起点可分裂、合并、替代、暂存和回流，不因最早记录而优先。

下一步：[阶段2｜联想与前期调研](<02_联想与前期调研.md>)。允许按问题回退。

## 二、核心判断：我们决定表达什么？

| 判断项 | 填写提示 | 填写内容 |
|---|---|---|
| 主题 Theme | 用一句话定义角色在世界中的位置与主题；可用「文化/时代 + 身份 + 处境」组织 | |
| 核心幻想 Fantasy | 观众想成为怎样的人，或从角色身上感受到什么？用一句话概括其吸引力 | |
| 功能 Function | 角色在玩法、叙事或画面中承担什么作用？这一作用要求角色具备什么能力或行为？ | |
| 独特之处 | 对比同类，最值得保留的新意是什么？可来自性格、处境、行动方式或设计矛盾 | |
