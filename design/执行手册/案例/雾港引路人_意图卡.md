## 二、核心判断

| 判断项 | 填写内容 |
|---|---|
| Theme | 潮汐机械城里的普通引路工，在全城失去路标时承担公共责任 |
| Fantasy | 我不是拯救世界的强者，但可以让身边的人走出迷雾 |
| Function | 标记安全方向、照亮下一步并腾手接人；叙事作用是以小行动让群体重新前进 |
| 独特之处 | 让自己成为可见路标，却避免英雄式武装；光服务地面与同行者 |
| 第一眼 / 第二眼 | 先看见灯与空手的引导关系，再看见分节装备的修补痕迹 |
| 关键矛盾 | 必须显眼与性格克制；携带装备与伸手帮助相冲突 |
| 必须体现 | 普通成年人的两臂双腿；灯/标记具有可解释携带方式；至少一手可空出；脚下行动可读 |
| 避开 | 巨炮式灯具、覆盖面部的王冠、宗教或现实救援机构徽章、只靠粒子特效辨认职业 |
| 取舍优先级 | 引路功能与人形 → 接近感 → 轮廓差异 → 服装细节；功能不可读时先删装饰 |

| 表达词 | 本角色含义 | 可观察线索（待图像验证） |
|---|---|---|
| 可靠 | 能站住并接人 | 支撑脚明确；负重靠躯干，不悬空 |
| 克制 | 光为行路服务 | 一处主亮点，其他装备不争亮 |
| 接近 | 允许陌生人靠近 | 面部无遮罩；空手掌朝来者 |
| 行路 | 持续移动而非定点战斗 | 脚与下摆分开；主道具不过度遮脚 |

一句话意图：一个生活在潮汐雾港的夜班引路工，以克制的路标与伸出的手带居民走向高台，让人感到普通人也能成为依靠；独特之处是显眼的公共责任与不张扬的性格共存。

### 使用与结构边界

| ID | 不变量 | 可容忍偏离 / 未定内容 |
|---|---|---|
| I1 | 成年普通人，两臂双腿，面部可见 | 5–8 头身可探索，身材与性别表达未锁；不改成自动机械或儿童 |
| I2 | 引路灯/标记有明确支撑，非武器 | 肩背、腰挂、可移动框架均可；虚构晶体可供能，不宣称现实工程可用 |
| I3 | 至少一手可腾出接人，行走时不被装备完全占用 | 另一手可操作灯；不得两手持续举重物 |
| I4 | 竖版全身及 180×240 缩略图中主道具与伸手关系需可辨 | 色相、饰品可变；缩略读取现在只是目标，尚未测试 |

## 三、交给阶段二

| 问题 | 类别 | 依据与可观察目标 |

| Q2 去掉文字与发光，什么大形仍像可跟随的路标？ | 气质/造型/同类；I4 | 研究航标的形色编码；比较三种无纹样轮廓，检查道具与身体是否粘连 |
