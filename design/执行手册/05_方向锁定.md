# 阶段五｜方向锁定表

填写目标：选定一个主方向，明确 **为什么选它、哪些特征要保留、哪些地方还可以改变**。

人和 AI 使用同一张表。按「比较与选择 → 设计支柱 → 下一轮重点」填写；选择依据来自真实候选图，最终取舍由设计者确认。

## 一、比较与选择：我们决定深入哪一稿？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 比较依据 | 附[第四阶段](04_方向探索.md)候选图，重读[角色意图](../阶段一_角色意图卡_模板.md)中的优先级；缺关键动作或配色验证时先补图 | |
| 并排条件 | 统一展示高度、背景、相近视角与完成度；先看剪影与大色块，再看内部结构，不把精修程度当成方案优势 | |

| 比较项 | 填写提示 | 各候选的差异与判断 |
|---|---|---|
| 角色幻想 | 哪一稿最能让人感到角色的吸引力？指出画面上起作用的特征 | |
| 比例与轮廓 | 比较体量、重心、关键间隙和道具关系；缩小时哪个更容易辨认，为什么？ | |
| 功能关系 | 比较穿戴、持握和代表动作是否成立；哪一案更支持角色的行动方式？ | |
| 色彩与细节 | 比较大色块、焦点与细节密度；能否突出身份、保持主次，有没有过多装饰抢走注意？ | |
| 风格协调 | 有项目标杆时并排看夸张程度、形状语言与细节密度，注明来源；没有时写本角色要遵循的风格取向 | |

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 主方向与理由 | 明确选定一稿并附图，按意图优先级说明理由；审美偏好可以成为理由，但要说清喜欢什么 | |
| 接受的取舍 | 选它会失去哪一案的什么优势？为什么仍值得？必须满足的功能与表达要求不能靠总分抵消 | |
| 其他方案 | 保留未选稿及暂不采用的原因；若想借用其中的特征，写清用途与冲突，先补比较稿再决定 | |

## 二、设计支柱：哪些特征定义了这个角色？

提炼 2—3 条「意图 → 视觉特征」，在选定稿上标出位置。只写能指导修改的要点；后续评审用这些要点解释保留或修改的理由。

## 三、下一轮重点：继续完善什么，何时重新选择？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 优先完善 | 写下一轮最重要的 1—3 个问题，以及希望看到的改善；分清未解的设计问题与可自由尝试的细节 | |
| 重新打开方向 | 写什么情况会改变本次选择：动作不成立、用途改变、与意图冲突或审美取向改变；说明影响哪条支柱，保留旧稿，补图后重新决定 | |
| 完成检查 | 对照真实选定稿，能否清楚说出必须保留、可以修改和下一步重点？尚未确定主方向或关键依据不足，回第四阶段补试 | |
| 接手者复述 | 请实际接手者说出以上三点，记录误解并修正说明；没有真人评阅就写待评阅，不把填完表当作已验收 | |
| 交给第六阶段 | 带选定稿、设计支柱及未解问题进入[评审收敛](06_评审收敛.md)；未确认的选择明确写暂选 | |
