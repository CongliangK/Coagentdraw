# 阶段2｜联想与前期调研

> 现行手册；稳定 ID：`research_imagination`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

承接用户 58b2444 阶段二新版：带着意图出发 → 广泛接触素材 → 在画布上建立联想 → 留下初步意象，随时往返。入口可以是多个起点，不是唯一意图卡。主要成果是可持续扩展的 Krita 角色想象板，不是链接清单。

素材入口包括已有角色与人物塑造、美学与艺术设计、现实服装和生活器物、行动表情与关系、环境和生活世界、文本叙事片段、动植物机械等意外联想；这些不是逐项配额。允许“被吸引但暂时不知为什么”。搜索重复时换领域，不继续找同款。

在 Krita 将图片逐张置于普通图层，文本、圈示、草图独立成组；自由移动缩放、先铺开再聚簇，允许冲突和多个可能。人物照片、时装、建筑与独白可以并置；服装暂放在人物旁、颜色仅有倾向也是合格中间状态。反复吸引人的联系靠近或放大，未用的留旁边，不压缩成固定两三张主参考。出现人影、神情、行动或情境就留短句、拼贴或姿态小稿，不拼接既有角色的标志性设计。

联想性调研与事实性核对交织但不互相替代。文化含义、功能、连接会影响设计时再针对性查证；事实检索预算不限制整个灵感池。来源 ID 关联本地原图、作者/机构、标题、网址及已知限制；未知明确记未知，摘录注明范围。区分可观察事实、创作联想、待核实判断；第三方资料留本地，发布前另核权限。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 当前入口 | 关联哪些文本起点、感受或未知？可以多个 | |
| Krita 想象板 | 填文档与素材簇位置，保证材料可直接观看 | |
| 最有感觉的联系 | 哪些图、文字、服装、动作放在一起产生了新想象？ | |
| 初步意象 | 人物可能有什么体态、衣着感、神情和行动？可有多个 | |
| 事实问题 | 只记录影响设计且需要核对的问题；观察与联想分开 | |
| 来源与未解处 | 记必要来源 ID；不要求逐图论文 | |
| 带入选择 | 哪些意象值得汇总成创意，哪些仍留在旁边生长？ | |

**完成与交接：** 看板能想象人物的体态、衣着感、神情、行为与生活情境，并指出有生命力的素材联系即可交接；可以仍有多个人影、成熟度不同。若仍没画面，换入口、补生活动作或快速拼贴，也可回阶段一。作者判断什么打动自己，AI 不能代称。
