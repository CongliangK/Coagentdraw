# 阶段4｜角色视觉探索

> 现行手册；稳定 ID：`character_exploration`。工具能力见[能力说明](<../工具能力与验证.md>)；共用规则见[手册导航](<README.md>)。

围绕已定角色与当前锚点打开 Krita 角色设计稿。本轮默认**拼贴原型 → 结构线稿 → 基础色**，先用形体试验检验视觉猜想，再进入绘制；流程的实际收益待真实作品验证。有合适的既有原型就从当前问题继续，不为证明流程重做一次。

## 起步与操作分工

- **已有角色稿：** 从当前有效主稿的保留分支开始，在探索组添加部件；沿用已定比例、画幅与身份保持项，只试本轮问题。
- **没有角色底稿：** 先采用作者提供或已允许使用、视角适配的比例底稿；没有现成底稿时，由具备实际能力的执行者用参考辅助的粗人形/简单块面建立基底，只需能看清身体比例与部件落位。若拟采用生成方法，先确认该次任务授权和可用能力，结果先候选；不为此前置新模型、Blender或精细手绘。尚无可用基底就留作待解决问题，先比较材料，不宣称已完成整身试拼。
- **资料可用但无法拆件或变形：** 助手给出目标部位、当前稿版本和拟调整的大小/方向，明确缺的是选区、裁切还是变形；由具备能力且获授权的执行者接续。并置参考可帮助比较意向，但不能登记成已经贴合角色的原型。若当前无人能完成该操作，保留输入和缺口，回搜更适配的材料或由作者决定简化方案。

实际执行者负责非破坏拆件、变形、绘制与保存，助手按自身能力承担其中可执行部分；作者负责保留、调整或放弃。确认范围与现有授权衔接，不新增逐步审批。检索说明见[02](<02_联想与前期调研.md>)，原型转清晰主稿的交接见[05](<05_角色方案收敛.md>)。

## 同画布对照、拼贴与编辑

直接从当前画布旁置的素材取用部件，在探索层试拼；草图、主稿和编辑结果分层保留，可并排或切换比较。作者接受并实际采用后才变更当前基底；导出隔离旁置素材。画幅与输出规则见[工作画布组织](<../Krita中枢创作流程_正式执行规范.md#工作画布与文档组织>)。

## 先在角色上试大型与协调性

1. 读 [02](<02_联想与前期调研.md>) 的本轮资料与尝试记录，确认当前画布版本、目标部件和要比较的问题。保留来源原图，将试用部件放在探索层/组，关键部件能独立移动、隐藏和调整；不强制新增机器预设或单独管理平台。
2. 按实际能力拆件、移动、缩放、旋转、扭曲或液化，先看身体、衣物、道具合起来的体量、比例、重心、轮廓和负形；细节与来源颜色此时不当成已确定设计。拼贴可以粗糙，但不能用不相容的视角/透视掩盖结构问题。当前没有合适底稿时先形成粗人形/比例基底，不强迫无参考独立手绘。
3. 回到整身比较：披风是否压住主体，大锤是否与身体和持握协调，主形/辅形的方向、比例和分布是否支持核心幻想。剪影是轮廓检查手段，可用观察副本或显示诊断；不要求先单独画完剪影才允许拼贴。身体或主服装改变时，重新检查依附装备和细节。
4. 由作者决定保留、调整或放弃。记录可观察的理由，例如过重、太窄、遮住发廓或连接不成立；把理由转成下一次搜索/变形目标。资料本身不适配就回 02，不以继续细化补救坏大型；核心方向不成立可回 03。未选只在本轮暂存，不能升级永久拒绝或删除原图。

候选以相近尺度、背景、视角和完成度并排；案内比较可一次改一组变量。数量由问题决定，不设强制八张/六张。填黑复制不是造型探索，也不靠拼贴碎片数量证明独特性。

## 原型成立后重构线稿，再试基础色

保留的是比例、轮廓、服装/装备关系等设计决定，不是照抄来源轮廓与纹理。以原型为依据重构自己的结构线稿，重新设计连接、厚度、遮挡、裁片、缺失面和具体细节；软布垂落、硬件支撑、穿脱开口与固定位置须成立。边缘检测、自动描边或换纹样不等于原创结构线稿。代表动作检查穿戴、持握与活动；问题回到相关部件或大型修正。

结构基本可读后，用独立基础色层比较颜色分区、面积和主次，再在预期背景观察。原素材色暂存为参考，不自动成为角色色彩决定；不强制厚涂。线稿与基础色须能继续分别修改，作者保留取舍权，AI可辅助绘制；不能以工具调用或文本描述代替真实画面。

### 简短示例：把“宽披风”变成当前角色的设计

以下仅为教学假设，没有对应作品或作者决定。锚点是“增加肩部体量、保留腰部负形”：02 找到肩部完整、视角适配的设定图，取得材料后才可在04的探索组试贴。若整身观察发现披风遮住手臂、压没腰线，先缩短下摆或收窄展开角；仍无效就放弃该材料，回搜开口更清楚的款式。尝试记录引用来源、原型组/层与预览版本，写明实际反馈。

若作者选择保留，带入线稿的是肩部体量、下摆长度和负形关系；重新设计领口固定、肩部厚度、手臂通道和裁片，处理原图遮住的连接，不沿碎片边缘直接描一圈。结构线稿中隐藏临时拼贴后仍应读得清这些关系，再试本角色的基础色；未画出的背部留给后续设计。04说明已探索到哪一步，05继续清晰主稿和实际修订，不要求在两阶段各重画一次。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 本轮要看清什么 | 当前角色、锚点、画布版本和比较问题；引用02同一尝试 | |
| 剪影/大形 | 记录真实拼贴位置：身体、衣物、道具合起来是否协调？轮廓检查发现什么？ | |
| 粗线稿/穿戴 | 哪些结构已重新设计，哪些仍只是临时素材？ | |
| 结构与动作 | 谁压住谁、怎样固定、怎样活动？缺失面和不适配视角是否已处理？ | |
| 平涂配色 | 线稿后比较颜色在哪里、占多少；未做就标未做 | |
| 对比观察 | 同尺度看整体与局部，指出具体作用和代价；决定写回02尝试与反馈 | |
| 下一步 | 保留、调整或放弃哪些原型；回搜资料、重构结构还是交05收敛？ | |

**完成与交接：** 能指出真实原型与探索图的差异、协调性和代价，有可供收敛的方向。各候选不必探索所有维度，但交 [05](<05_角色方案收敛.md>) 时须说清原型、结构线稿、基础色各自到哪一步，未画/未测不能标完成。拼贴只是原型，不代替05的原创清晰主稿。

选区、变形、液化和笔刷等操作由具备相应能力且获授权的执行者完成；当前插件没有通用笔刷/变形/滤镜接口，现有CLI不能自动完成以上动作。能力不足就保留输入与具体缺口，不用空层、脚本成功或生成占位图冒充实际试拼。共用非破坏、目标核对和安全回填规则继续适用。
