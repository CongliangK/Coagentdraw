# 阶段7｜插画方案探索

> 现行手册；稳定 ID：`illustration_planning`。这是创作目标，不表示程序已迁移；共用规则见[手册导航](<README.md>)。

角色与三视图成立后，另开 Krita 插画文档。用低成本线稿小稿比较画面事件、人物与环境关系、视角远近俯仰及动作；试画幅裁切、透视支撑接触与遮挡，再给有潜力稿补明暗和冷暖光色。拼贴、AI 候选或已有三维辅助均可，不前置建设 Blender 管线。

缩小看事件与焦点，必要时请真实读者描述“谁在做什么、感受到什么”。作者确认的是本轮画面关系，不是再确认角色外貌。早期插画灵感可保留，不能冒充本阶段已完成。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 角色依据 | 引用已确认三视图和保持要点 | |
| 画面事件 | 角色正在做什么，最重要的感受或关系是什么？ | |
| 用途与画幅 | 记录本次真实用途、尺寸和比例；未指定不冒充已确认 | |
| 镜头与动作 | 以图比较，不只写“有张力”“史诗感” | |
| 构图线稿 | 主次、重心、空间和动作读取是否成立？ | |
| 明暗/光色小稿 | 简单大块即可；不要把所有光照问题留给精绘 | |
| 表达检查 | 缩小看能否读到想表达的事件，而不只是角色精致？ | |
| 插画确认稿 | 作者选择本轮方案；记录哪些画面关系应保持 | |

**完成与交接：** 事件、镜头、动作、构图、基本明暗光色都有可见依据，作者确认本轮方案和保持关系。读图不清回构图/光色，角色矛盾回五/六，不静默换装。
