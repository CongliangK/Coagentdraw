# 阶段二｜前期调研

填写目标：找到支撑角色设计的参考，并说清楚准备怎样使用。

人和 AI 使用同一张表。带着[角色意图卡](../阶段一_角色意图卡_模板.md)中的未知，按「研究问题 → 参考与转化 → 设计依据」填写。

## 一、研究问题：现在需要弄清楚什么？

| 研究方向 | 填写提示 | 要回答的问题 |
|---|---|---|
| 主题与文化 | 哪些时代、文化或身份信息会影响设计？先查什么，才能避免只借用表面符号？ | |
| 身份与功能 | 角色如何穿戴、持握、移动或携带工具？哪一处结构需要真实依据？ | |
| 气质与视觉表达 | 要用哪些比例、形状、剪裁、材料或色彩表达角色？哪些还没有把握？ | |
| 同类与差异 | 同类角色常用什么表达？哪些共性有用，哪些惯例准备突破？ | |

## 二、参考与转化：看到什么，准备怎样用？

每条关键参考填写一组；只保留能回答上述问题的材料。搜索时把对象、具体结构或动作组合成关键词，再核对原始出处。

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 对应问题 | 这条参考回答上表哪一个问题？ | |
| 来源与使用限制 | 记录作者或机构、标题、原始链接与图片位置；注明已知使用限制，授权不明时不当作可自由转载素材 | |
| 看到什么 | 写可观察的形状、连接、材料或动作关系；来源没有说明的内容标为推测 | |
| 为什么适合 | 它怎样支持本角色的身份、功能或核心幻想？ | |
| 准备怎样转化 | 保留哪种结构或关系，改变哪些比例、组合或用途，使它成为本角色的设计？ | |
| 尚待验证 | 哪个判断还缺依据？需要继续查找，还是交给画稿验证？ | |

## 三、设计依据：带着什么进入提案？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 主参考 | 选出最能支撑方向的 2—3 条参考，写明各自负责解决什么；补充参考按问题归类 | |
| 注释参考板 | 将主参考与结构标注放在一起，标明来源及转化想法；填写板图位置，也可直接用本页记录对应原图 | |
| 设计启示 | 写下值得进入提案的形状、结构、动作或组合关系，以及它们来自哪条依据 | |
| 完成判断 | 核心选择能否说清来源、适用理由和转化方法？若仍只是好看的图片，回到第二部分补判断 | |
| 下一步 | 将可用想法和待验证问题交给[创意提案](03_创意提案.md)；若问题本身不清楚，先回意图卡收窄目标 | |
