# 阶段八｜最终插画

填写目标：让已确定的角色在一个画面事件中，鲜明地表达核心幻想。

人和 AI 使用同一张表。按「画面事件 → 构图与光色 → 完成检查」填写，随实际绘画补上稿件位置和判断；填表不能代替成图、源文件或真实评阅。

## 一、画面事件：这一刻为什么值得画？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 设计依据 | 对照[角色意图卡](01_立项定位.md)和已确认设计稿，填稿件位置及本图必须保持的角色特征 | |
| 核心幻想 | 本图最想让观众感受到什么？从意图卡选择本次重点，不重写角色设定 | |
| 关键瞬间 | 角色正在做什么、为何行动、是什么情绪？这一瞬间怎样体现上述吸引力？ | |
| 人物与环境 | 角色在与谁或什么发生关系？动作、视线、道具和环境中，哪些线索能让观众读懂事件？ | |
| 交付用途 | 沿用项目约定的观看场景、画幅、尺寸与格式；有多种裁切时，注明必须保留的表达 | |

## 二、画面选择：怎样让观众看见重点？

| 项目 | 填写提示 | 填写内容 |
|---|---|---|
| 构图比较 | 画有实质差异的小稿，数量按问题决定；比较观众位置、远近、俯仰与人物关系，填各稿位置、表达效果和损失 | |
| 选定构图 | 选哪稿、为什么？动作线怎样引导视线？按交付画幅试裁切，检查头、手、关键道具和轮廓是否仍清楚 | |
| 空间与动作 | 用简化体块检查透视、支撑、接触和遮挡；写出需要先修的关系，再进入细化 | |
| 明暗安排 | 画少量灰阶小稿；缩小看先读到什么、再读到什么，主体是否与环境分开，哪里抢走焦点 | |
| 光色决定 | 做小尺寸色稿，比较必要的光源与冷暖变化；选定光向、画面情绪和焦点，核对光照下的角色主色 | |
| 精修重点 | 按观看顺序分配结构、边缘和材质细节；每轮只解决明确问题，缩回全图检查是否改善事件表达 | |
| 修改保留 | 画改、AI 细化或放大均用新层或副本，保留修改前稿；检查整图的脸、服装、道具与边界外变化，设计漂移则拒收，结构错误先画改 | |

## 三、完成检查：画对了，也表达出来了吗？

| 检查项 | 填写提示 | 检查结果 / 稿件位置 |
|---|---|---|
| 角色身份 | 对照已确认设计，逐项核查比例、脸、服装与道具；区分透视和光照造成的合理变化与擅自改设定 | |
| 观众读图 | 请真实读者先描述「谁在做什么、感受到什么」，记录原话，再对照核心幻想判断；尚无反馈写待评阅，不用 AI 评分代替 | |
| 画面完成度 | 在实际观看尺寸检查事件、焦点与裁切；近看结构、穿插、边缘和接缝。记录还影响表达的具体问题 | |
| 停止精修 | 核心表达、身份、结构和规格都成立后，剩余修改是否有明确收益？确定停止，或只补一项可检查的改善；未过关键检查不标成品 | |
| 真实交付 | 填最终图、可编辑源文件及构图／灰阶／色稿位置；实际打开核对尺寸、色彩、裁切与图层可编辑性。未打开写未验证，缺作品写未完成 | |
| 必要回退 | 读图不清回构图或光色；局部结构错先修画面；设计本身不成立回评审，需改变已定角色特征回方向锁定。保留旧稿，写清重查什么 | |
