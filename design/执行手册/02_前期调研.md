# 阶段二｜前期调研

阶段目标：围绕角色意图，借助丰富的图像与文本激活想象，逐渐看见 **角色可能的样子、气质、行动与生活世界**。

如果说[阶段一](01_立项定位.md)主要用文字描述想创造怎样的人，这一步就是让文字与图像相遇，形成带有画面感的想象。它不只是查证设定、寻找服装结构或为已有方案补依据，也是在素材中发现原先没有想到的可能。

主要成果是一张可以持续扩展的**角色想象板**：在大画布上放入参考图片、文本片段、联想注释及随手草图，让朦胧的角色逐渐活起来。本页用于记录线索与阶段交接，不代替画布；不要求给每张图片填写一套分析表。

人和 AI 可共同搜集、整理和提出联想；什么真正打动创作者、想沿哪种感觉继续，由创作者判断。按「带着意图出发 → 广泛接触素材 → 在画布上建立联想 → 留下初步意象」推进，随时往返，不必依次填满所有表格。

## 一、带着意图出发：我们想遇见怎样的人？

重读[角色意图卡](01_立项定位.md)，带上核心幻想与必要约束，但不急着预先规定外貌。第一阶段列出的调研问题是入口，不是素材准入清单。

| 项目 | 填写提示 | 简短记录 |
|---|---|---|
| 想唤起的感受 | 这个角色最吸引人的体验是什么？哪些表达词值得先去看图、读材料？ | |
| 已有的朦胧印象 | 脑海里已经闪过什么人影、神情、动作或场景？没有画面也可以从一个词出发 | |
| 必须带上的条件 | 哪些身份、用途或世界观条件已确认？哪些仍可开放，不应提前当作定论？ | |
| 第一批入口 | 从哪些角色、美学、服装、人物、作品或文字开始找？允许在搜集过程中不断改写关键词 | |

## 二、广泛接触素材：什么让想象开始生长？

先看得丰富，再逐渐发现偏好。不只搜索与角色职业直接对应的图片，也顺着一种神情、一种服装节奏或一句文字跨领域寻找。既有作品与现实材料都可以成为入口；以下类别不是必须逐项完成的配额。

| 素材入口 | 可以关注什么 | 找到的素材 / 画布分区 |
|---|---|---|
| 已有角色与人物塑造 | 哪些角色、演员或人物肖像让你感到接近？可能只是眼神、姿态、矛盾感或某种吸引力，不必整个人都相似 | |
| 美学与艺术设计 | 时装、绘画、雕塑、摄影、建筑、平面设计中，哪些形状、色彩、质感或氛围令人心动？ | |
| 现实服装与生活器物 | 看真实的人怎样穿衣、劳动、携带工具；也看衣物的垂落、磨损、层次和使用痕迹带来怎样的感觉 | |
| 行动、表情与关系 | 人怎样站立、行走、战斗、休息或与他人相处？什么瞬间让你觉得“这个角色可能会这样”？ | |
| 环境与生活世界 | 他可能出现在怎样的街道、房间、自然环境和光线里？这些空间怎样影响他的气质与生活？ | |
| 文本与叙事片段 | 小说、诗句、史料、访谈或对白里，什么描述唤起了形象、情绪或行为？把关键片段放到图旁边 | |
| 意外联想 | 动植物、机械、自然纹理或其他不直接相关的对象，是否带来了新的感觉与组合可能？ | |

允许保留“被它吸引，但暂时不知道为什么”的材料。不要求每条参考立即证明用途、说明转化方法；也不把“找得多”当作完成标准。若搜索结果反复相似，换一类素材、一个领域或一组关键词，而不是只继续找同款。

## 三、在大画布上建立联想：这些素材放在一起，会发生什么？

建立角色想象板，可使用支持自由排布的参考工具或画布。保留素材本身的可见性，让创作者能够反复观看、移动和比较，而不是只留下链接或 AI 的文字摘要。

- **先铺开，再聚成簇。** 按感觉、动作、服装、环境或某种尚未命名的联系摆放，不必一开始分好固定栏目。
- **把不同来源放到一起。** 一张人物照片、一段文字、一套时装和一种建筑形状，可能共同唤起一个此前没有的角色。
- **写短注释，不写逐图论文。** 标出“吸引我的地方”“让我想到的角色表现”；暂时说不清的可以只圈出局部、标一个词。
- **允许冲突与多个可能。** 庄严与轻佻、精致与粗粝等不同感觉可以暂时并存；分成不同素材簇，不急着选定唯一方向。
- **有画面就顺手留下。** 可画姿态小记、拼贴、写一句场景或对白；这些是捕捉联想，不要求提前画出完整设计方案。
- **逐渐突出有生命力的联系。** 将反复引起兴趣的素材靠近、放大或标记；暂时不用的保留在旁边，不把探索输入压缩成固定的两三张主参考。

例如：旧礼服的整齐层叠、舞台演员克制的手势、一段关于执念的独白，放在一起，可能让人开始想象“一个连整理袖口都像在完成仪式的人”。此时不必立即决定袖口的最终设计，先记住这个人的感觉和行为。

| 画布记录 | 填写提示 | 记录内容 |
|---|---|---|
| 想象板位置 | 填可继续编辑的画布与便于查看的预览位置；尚未建立就写待建立 | |
| 正在生长的素材簇 | 哪些材料开始形成联系？可直接引用画布中的分区名或位置 | |
| 最有感觉的联系 | 哪种并置、反差或组合最让你想继续？写短句或直接在板上标注 | |
| 还想寻找的刺激 | 现在的板缺什么：人的神态、行动、生活气息，还是另一种完全不同的美学？ | |

### 来源与考据：支持想象，不取代想象

保留作者或机构、作品名、原始网址及已知授权限制，使用图片编号或画布标签关联即可，不必逐张写长篇论证。文字摘录标明出处与摘录范围；来源或授权未知时明确写未知，不当作可自由转载素材。搜集的第三方材料默认留在本地研究空间，公开发布前另行核对使用条件。

分清**素材中的事实、自己的联想和待核实的判断**。例如，“这张照片出现了某种穿法”是观察，“这种穿法让角色显得拘谨”是联想，“某时代普遍这样穿”则需要来源支持。

当文化含义、身份功能或器物构造会影响创作时，针对性补查依据；尚未查清的先标记，不必把所有结构问题都解决才允许想象继续。既有角色可启发气质、动作或表现，但不直接拼接其标志性设计作为自己的角色。

## 四、留下初步意象：现在开始看见谁了？

回看整张板，而不只是逐张解释图片。试着描述或画出开始浮现的人：可以仍然模糊，可以有几个不同的人影，不需要唯一答案。不是把参考各取一件拼成服装清单，而是说出这些素材共同唤起了怎样的角色体验。

以下记录可写在表里，也可直接放在画布旁，用短文、草图或拼贴表达。

| 意象线索 | 填写提示 | 当前想象 / 对应板上位置 |
|---|---|---|
| 外貌与气质 | 想象中的人影有什么体态、轮廓、衣着感觉与神情？哪些地方仍然看不清？ | |
| 行为与表现 | 他怎样站、走、看人、说话或使用物品？选一个最有感觉的动作或瞬间 | |
| 生活与情境 | 想象他出现在一个具体场景里：正在做什么，与谁或什么发生关系？ | |
| 吸引力与张力 | 哪些感觉开始相互加强，或产生有趣的矛盾？它们怎样回应角色意图？ | |
| 其他可能与未知 | 还有什么不同的形象值得保留？哪些是新联想，哪些需要补查或后续画稿验证？ | |

## 五、何时进入创意提案？

阶段成果是**角色想象板，以及由它唤起的初步意象与创作线索**。不是参考数量达标、表格填满，也不是已经完成角色设计。

| 完成与交接 | 判断提示 | 当前记录 |
|---|---|---|
| 开始看见角色 | 看着板，能否开始想象这个人的样子、气质和一个行动瞬间，而不只是复述设定词或列出服装部件？ | |
| 素材产生了联系 | 能否指出一些让想象生长的素材联系，而不是只有彼此孤立的漂亮图片？不要求解释每张图 | |
| 想继续创作的线索 | 哪些意象让创作者想试着画出来？记录具体的兴趣点；AI 可以建议，但不能替创作者宣称“已被打动” | |
| 带入下一阶段 | 将想象板、初步意象、必要事实依据和未解问题交给[创意提案](03_创意提案.md)，再组织成不同的设计解法；保留原始素材簇供回看 | |
| 若仍然没有画面 | 不因填完表而结束。换素材入口、补动作与生活场景，或试一次快速拼贴；若文字意图本身没有吸引力，再回阶段一讨论 | |

调研、提案与探索可以往返：产生新联想就记录，出现关键未知就回来补素材。本阶段不锁定最终外貌，也不要求先把所有参考论证完毕才进入创作。
